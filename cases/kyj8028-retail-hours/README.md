# 대형마트 의무휴업 평일 전환과 골목상권 매출

작성자: 강영재 (`kyj8028`)

동대문구의 의무휴업 평일 전환 전후로 골목상권 식품판매 매출이 어떻게 달라졌는지 서울 내 다른 자치구와 비교한다. 7주 과정에서는 자료 수집부터 품질 점검·분석·보고까지 이어지는 파이프라인 구축을 목표로 한다.

| 항목 | 내용 |
|---|---|
| 처치 | 동대문구, 분석상 시작 분기 2024Q2 |
| 비교 | 서울 내 20개 자치구 후보 — 정책 이력 추가 확인 필요 |
| 기간 | 2021Q1~2024Q4, 2023Q4·2024Q1 제외 |
| 지표 | 골목상권 육류·수산물·청과·반찬 판매 추정매출 합계의 자연로그 |
| 방법 | 이벤트스터디, 가짜 시행일 검정 |

프로젝트 범위와 일정은 [plan.md](plan.md), 분석 설정과 판정 기준은 [plan.yaml](plan.yaml)에 정리했다.

현재는 계획 작성 단계이며, 매출 원자료 수집과 분석은 아직 진행하지 않았다. 계획을 커밋·PR한 뒤 `fetch.py`와 사례별 검사를 구현할 예정이다. 비교 지역의 정책 이력과 공간 자료의 버전 호환성이 확인되기 전에는 인과효과 판정을 보류한다.
