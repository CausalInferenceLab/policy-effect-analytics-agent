# 원본 수집과 잠정 패널 구축 결과

2026-10-27 · 작성: 김인엽(inshining)

데이터 조회 가능성 확인 다음 단계로, **실제 원본 수집·정제·사고와 인구의 결합**을 실행했습니다. 2014~2019년의 잠정 패널 **1,368행**을 생성했습니다. 전체 경계를 통일한 최종 분석 표본은 아니며, 정책 효과는 추정하지 않았습니다.

## 확보한 자료와 검증

| 항목 | 결과 | 기록 |
| --- | --- | --- |
| TAAS 사고 원본 | 2014~2018년·2019년 각각 2페이지, 공개 XML 4개 | [taas-qc.json](taas-qc.json) |
| 행안부 인구 원본 | 2013~2018년 12월, CSV 6개 | [population-qc.json](population-qc.json) |
| 인구 정규화 | 합계 행을 표시한 1,676행. 65~99세와 100세 이상 합산 | `data/population.csv` |
| 사고 정규화 | 원본 시군구×연도 1,379행 중 1,368행 연결, 11행 보류 | `data/accidents.csv`, `data/taas-unmatched.csv` |
| 잠정 결과 패널 | 229개 지역 코드, 1,368행. 227개 코드는 6개 연도 모두 존재 | [panel-qc.json](panel-qc.json), `data/outcome-panel.csv` |
| 자동 검사 | 파서·필터·합계·지역 연결·해시 변조 등 29개 테스트 통과 | `test_population.py`, `test_taas.py`, `test_panel.py` |

TAAS는 **가해운전자(1당사자)가 65세 이상인 교통사고**를 사용했습니다. 노인 피해자 사고 통계와 다릅니다. 공개 조회의 연도·시군구 조건을 적용했고, 조회 기간의 최대 5년 제한에 따라 두 구간으로 나눴습니다. 확보 형식은 XLSX가 아닌 공개 통계의 XML 응답입니다.

모든 페이지의 시군구 합계→시도 합계→전국 합계가 일치했습니다. 전국 수치는 [국민권익위원회 공식 자료](https://m.acrc.go.kr/boardDownload.es?bid=1013&list_no=30601&seq=1)의 2014~2018년 값 및 [행정안전부 안전한TV](https://www.safetv.go.kr/base/video/view?idx=1314)의 2019년 값과도 일치했습니다.

| 사고 연도 | 공식 전국 사고 건수 | 연결 행 | 보류 행 | 연결된 사고 건수 | 보류된 사고 건수 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2014 | 20,275 | 227 | 3 | 19,840 | 435 |
| 2015 | 23,063 | 228 | 2 | 22,950 | 113 |
| 2016 | 24,429 | 228 | 2 | 24,316 | 113 |
| 2017 | 26,713 | 228 | 2 | 26,601 | 112 |
| 2018 | 30,012 | 228 | 2 | 29,885 | 127 |
| 2019 | 33,239 | 229 | 0 | 33,239 | 0 |

각 연도의 **연결 사고 + 보류 사고 = 전국 사고**도 검사했습니다. 잠정 패널의 합계를 전국 총계로 표시하지 않습니다. `data/taas-national.csv`는 이름과 달리 전국·시도·시군구의 모든 계층을 보존한 감사용 표이므로, 전체 행을 더하면 중복 집계됩니다.

## 연결·보류 기준

부산의 `진구`→`부산진구`는 6개년 각각 16개 구군 중 15개 정확 일치와 유일한 잔여 쌍을 근거로 연결했습니다. 원본 명칭과 수치는 유지하고 6행의 변환 이력을 QC에 기록했습니다. 판단 과정은 [정제 노트 01](cleaning-step-01.md), 명세는 [이름 대응 근거](region-name-crosswalk.json)에 있습니다.

연초 인구는 사고 연도의 **직전 12월 31일** 자료입니다. 지역명은 시도를 포함한 전체 명칭으로 연결하고, 지역 코드는 행안부의 문자열 10자리 코드를 보존했습니다.

`crashes65_per_10000_residents = 10000 × crashes65 / population65_start`

지역×연도 중복, 시도 합계 유입, 같은 연도의 도시·하위 구 중복은 0건입니다. 세종의 광역 합계와 같은 이름의 기초 행도 구분했습니다. 전주처럼 TAAS가 도시 전체를 제공하는 경우에는 인구 도시 합계를 사용하고 하위 구를 함께 넣지 않았습니다. 별도 검토자가 모든 결합 행의 원시 사고 건수·분모·기준일·코드·사고율을 독립 계산으로 대조했습니다.

다음 11행은 원본에 보존하되 사고율 계산에서 보류했습니다. 미연결 값을 0으로 바꾸거나 인구에 비례해 배분하지 않았습니다.

| 원본 지역·기간 | 행 수 | 보류 사유 |
| --- | ---: | --- |
| 인천 `미추홀구`, 2014~2018 | 5 | 과거 인구는 남구 명칭·코드. TAAS의 과거 값 재표기와 경계 동일성 확인 필요 |
| 청주시·청원군, 2014 | 2 | 2014-07-01 연중 통합. 연초 인구와 사고 집계의 경계 일치 미확인 |
| 청원군, 2015~2018 | 4 | 통합 후에도 TAAS에 0건 행이 남음. 폐지 지역을 정상 관측으로 취급하지 않음 |

청주 통합일은 [청주시 공식 연혁](https://www.cheongju.go.kr/www/contents.do?key=545)에서 확인했습니다. 같은 이름·코드가 있다고 경계가 같다고 가정하지 않습니다. 227개 지역의 6개년 관측 존재는 **시간적 완전성**이며, 전체 지역의 공간 경계 검증을 뜻하지 않습니다.

주민등록인구는 등록구분 전체(거주자·거주불명자·재외국민), 남녀계이며 외국인을 제외합니다. 재외국민은 2015년 1월부터 포함되는 정의 변화가 있습니다. 사고는 발생지, 인구는 주민등록지이므로 이 비율은 주민인구 대비 지역 사고 발생 빈도입니다. 면허소지자 위험이나 운전거리당 위험으로 해석하지 않습니다.

## 재현 방법과 산출물

저장된 원본에서 다음 순서로 재생성합니다. 수집·정제·결합 코드는 Python 표준 라이브러리만 사용하며 추가 설치가 필요 없습니다. 작업 폴더 루트에서 실행합니다.

```sh
python3 cases/inshining-elderly-driver/population.py
python3 cases/inshining-elderly-driver/taas.py
python3 cases/inshining-elderly-driver/panel.py
python3 -m unittest discover -s cases/inshining-elderly-driver -p 'test_*.py'
```

처음 수집하는 사본에서는 인구에 `--download`, 사고에 `--fetch`를 사용합니다. 사고 수집은 먼저 만든 `data/population.csv`를 지역명 기준으로 사용합니다. 이미 TAAS 원본이 있으면 `--fetch`는 덮어쓰지 않고 중단합니다. 기존 원본은 QC 해시와 일치해야 재생성하며, 결합 입력도 수집 QC의 파생파일 해시와 대조합니다. 수집시각과 QC 생성시각은 재실행에 따라 달라질 수 있지만 정규화 데이터의 해시는 동일하게 재현됩니다.

- `population.py`: 공식 인구 CSV 수집, 연령 합산·계층 합계 검사.
- `taas.py`: 공개 조회 수집, 기간·필터·페이지·합계 검사, 불명 지역 보류.
- `panel.py`: 검증된 사고·인구 결합, 비율 계산, `data/panel-coverage.csv`와 QC 생성.
- `data/raw/`: 원본 10개. 출처·조건·취득시각·해시는 두 수집 QC JSON에 기록.
- `data/outcome-panel.csv`: 결과 지표만 포함. `treated`·`first_treat`는 아직 없음.

원본·가공 데이터는 `.gitignore`의 `**/data/`로 제외합니다. QC·코드는 재현 명세이며, 원본 데이터를 포함한 제출 묶음이 아닙니다. 공개 조회의 존재를 재배포나 반복 자동수집 허가로 간주하지 않았으며 해당 이용 조건은 미확정입니다. 비공개 로그인 자료를 사용하지 않았고, 임시 세션·서버 식별값은 원본/QC에 남기지 않았습니다.

## 효과 추정 전에 남은 조건

1. 보류 지역의 명칭·경계 대응 및 다른 포함 지역의 경계 일관성을 확정합니다.
2. [정책 기록](policy-register.yaml)을 분석 대상에 대해 완성하고 실제 제공 시점으로 처치를 결합합니다. 서울·경기는 2019년 미도입 비교군이 아닙니다. 전주는 2020년부터 시행했다는 공식 설명, 군산은 2020년 최초 시행 근거가 있는 비교군 후보입니다. 전주의 모든 선행사업 부재와 두 도시의 적격성까지 확정한 것은 아닙니다.
3. 코호트별 사전 3개년·도입 다음 해·해당 시점 미도입 비교군과 독립 정책 군집 수를 확인합니다. 부산의 2019-11-11 안전속도5030 등 동시 정책도 기록합니다.
4. 원하는 코호트별 DiD와 소수 군집 추론의 실행 경로를 검증하고 최종 계획을 고정합니다. 현행 상위 파이프라인의 일반 이벤트 스터디를 그대로 원하는 시차 DiD로 취급하지 않습니다.
5. 상위 프로젝트의 계획 선행 커밋·하루 이상 간격 규칙을 충족한 후 효과를 계산합니다. 현재 폴더는 Git 저장소가 아니며 커밋·이슈·PR·사전등록을 만들지 않았습니다.

계획 작성 전 보도·선행연구를 알고 있었고, 이번에 전국 총계와 원시 지역값·결합 범위를 확인했습니다. 자료 열람 이력을 공개하며, 지금 만든 결과를 사전등록 이후 분석으로 소급 표시하지 않습니다.
