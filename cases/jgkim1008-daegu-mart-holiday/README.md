# 대구시 대형마트 의무휴업일 평일 전환과 지역 소매업 판매

작성자: `jgkim1008` · 트랙 B (가설과 분석)

2023년 2월 대구시가 대형마트 의무휴업일을 일요일에서 월요일로 바꾼 뒤, 대구의 슈퍼마켓·잡화점 판매가 일요일 휴무를 유지한 다른 광역시와 비교해 어떻게 달라졌는지 살펴본다.

| 항목 | 내용 |
|---|---|
| 처치 | 대구광역시 (8개 구·군 동시 전환), 분석상 시작 분기 2023Q2 |
| 비교 | 부산, 인천, 광주, 대전, 울산 (분석 기간 중 일요일 휴무 유지) |
| 기간 | 2019Q1~2023Q4, 전환 분기 2023Q1은 추정에서만 제외 |
| 지표 | 슈퍼마켓·잡화점 판매액지수(주), 대형마트(보조), 승용차·연료소매점(가짜 지표) |
| 방법 | 이벤트 스터디 (처치 1곳 → 무작위화 추론), 가짜 시작일 검정 |

## 정책 설명

- **정책**: 대형마트 의무휴업일 평일 전환 (유통산업발전법 제12조의2 — 의무휴업일은 공휴일이 원칙이나 이해당사자 합의로 공휴일 외 지정 가능)
- **경과**: 2022-12-19 대구시·구군·유통업계 평일 전환 협약 → 2023-01-13~02-02 행정예고·의견수렴 → 2023-02 8개 구·군 고시
- **시행**: 2023-02-12(일) 첫 일요일 영업, 2023-02-13(월) 첫 평일 휴무. 매월 둘째·넷째 일요일 → 둘째·넷째 월요일
- **대상**: 대형마트 17곳, 기업형슈퍼마켓(SSM) 43곳
- **특징**: 특·광역시 최초, 구·군 전체 동시 전환이라 처치 시점이 하나다

## 같은 주제의 다른 사례와 차이

[`YoungjaeKang-retail-hours`](../YoungjaeKang-retail-hours/)는 서울 동대문구 전환(2024)을 자치구 단위 상권 추정매출로 본다. 이 사례는 광역시 전체가 같은 날 전환한 대구를 광역시 단위 공식 판매액지수로 본다. 두 결과는 단위·지표·시기가 달라 직접 비교하지 않고, 방향이 같은지만 참고한다.

## 왜 이 질문인가

대구시는 전환 후 6개월 동안 전통시장 매출 +32.3%, 음식점 +25.1%를 발표했지만 대조군 없는 전년 동기 비교다. 같은 시기 다른 광역시도 소비가 회복 중이었으므로, 일요일 휴무를 유지한 광역시와 비교해 차이가 남는지 확인한다. 전통시장 매출은 이 자료에 없어 직접 검증하지 않는다.

## 설계 메모

- **분기 단위**: 시도별 업태 구분 판매액지수는 분기로 공표되는 것으로 보고 분기로 설계했다. 월별 자료가 확인되면 데이터를 열기 전에 계획 변경을 커밋한다.
- **기준 시점**: 상대시점 -1(2023Q1)이 제외되므로 `ref_period: -2`(2022Q4)를 쓴다.
- **사전 계수 범위**: `window: [-4, 2]`로 -4 이전을 한 묶음으로 둔다. 사전 계수가 많으면 사전추세 결합검정이 가짜 자료에서도 쉽게 기각된다(`hyun2-land-permit-spillover-2020` 점검 참고).
- **합성통제**: 처치가 1곳이라 합성통제가 적합하지만 공통 실행기에서 준비 중이다. 우선 이벤트 스터디 + 무작위화 추론으로 1차 추정하고, 합성통제가 준비되면 추가한다.

## 한계 (사전 기록)

- 처치 1곳·전체 6개 광역시로 추론력이 약하다. 무작위화 추론의 재배정 경우가 몇 가지뿐이다. 실행기 p값은 대조 5곳에서만 재배정해 대구가 가장 극단이면 약 0.001로 작게 표시되지만, 6곳 중 순위로 본 정확한 p값의 하한은 1/6≈0.17이다. 그래서 실행기 p값 대신 크기·방향과 6곳 중 순위로 조건부 보고한다. 판단 불가도 가능한 결과다.
- 2023-07-01 경북 군위군이 대구에 편입되어 2023Q3 이후 대구 통계 범위가 바뀔 수 있다.
- 광역시 단위 분기 지수라 마트 주변 상권 효과·요일 효과가 희석된다.
- 대구 인접 경북(경산 등)으로의 소비 이동이 섞일 수 있다.
- 2024년부터 평일 전환이 전국에 확산되어 분석 기간을 2023Q4에서 끊었다.
