# 강남대로 후속 분석에 적용한 논문·공식 분석자료

2026-10-28에 확인했다. 검색 결과나 초록만으로 방법을 옮기지 않고, 아래 두 논문의 본문과 국토교통부 첨부자료를 읽었다. 원문은 Git 제외 경로에 보관하고 [출처·해시](research-sources.json)와 자체 요약을 남겼다. 이번 결과는 공개 집계자료를 이용한 후속 탐색이며 논문의 재현 실험이 아니다.

## 1. 정류장마다 다른 시간대 패턴을 보는 근거

박수진·양재환(2025), **「Soft-DTW 기반 클러스터링을 활용한 중앙버스전용차로 정류장 정체 유형 분석」**, 대한교통학회지 43(6), 761–774. [학회 원문](https://www.jkst.or.kr/articles/article/2XzE/), [PDF](https://www.jkst.or.kr/articles/pdf/2XzE/kst-2025-043-06-5.pdf), DOI `10.7470/jkst.2025.43.6.761`. 발행일 2025-12-31.

본문 765–768쪽에서 정류장 간 출발시각 차이로 통행시간을 정의하고, BMS·현장 자료를 사용해 15분 단위 특성을 비교하는 방법을 확인했다. 강남대로 구간도 분석 대상에 들어간다. 시간대별 패턴의 유사성을 Soft-DTW로 비교하고 군집 수를 검토한다.

**이번에 반영:** 남행·북행과 정류장 구간별 결과를 분리하고 07~22시 곡선을 만들었다. 저녁 전체 평균 하나가 지역별 차이를 가릴 수 있으므로 구간 그림도 함께 제공한다. **그대로 적용하지 않은 부분:** 우리의 시간당 평균 필드가 논문의 출발→출발 정의와 같다는 근거가 없다. 15분 자료·정차시간·현장 관측이 없어서 군집을 정체 원인으로 명명하지 않았다. 본문의 실루엣 값도 작아, 군집 수를 고정해 해석하기보다 별도 안정성 검증이 필요하다. 논문의 특정 구간 수치나 조사시점을 우리의 2024년 비교값으로 사용하지 않았다.

## 2. 버스가 빨라지는 것과 승객 편익을 구분하는 근거

하희동·김도경·최영우(2025), **「대기행렬 기반 중앙버스전용차로 정류장 운영전략 개발」**, 한국도로학회논문집 27(4), 71–83. [학회 본문](http://www.ijhe.or.kr/journal/article.php?code=95282), [DOI](https://doi.org/10.7855/IJHE.2025.27.4.071).

송파대로의 정류장을 대상으로 BMS·교통카드·교차로 운영 자료를 결합하고, 대기행렬 지체와 정류장 운영 대안을 평가한다. 정류장 건너뛰기 등 운영 변경의 통행 개선과 추가 보행·대기 부담을 함께 고려한다. HTML 전체 본문, 특히 자료·방법을 설명한 3장을 검토했다.

**이번에 반영:** 버스 구간 지수, 운행횟수 기록, 승차 기록, 일반 차량 속도·교통량을 별도로 산출했다. 운행횟수는 정책으로 바뀔 수 있는 결과이므로 자동으로 인과 회귀의 통제변수로 넣지 않았다. **현재 불가능한 부분:** 시간당 운행횟수만으로 배차간격 변동·대기행렬 길이·승객 대기시간을 계산하지 않는다. 승차/운행횟수도 재차 인원이나 좌석 점유율로 부르지 않는다. 송파대로의 결과 크기를 강남대로에 적용하지 않았다.

## 3. 실제 정책의 대상·방향·비교일을 정한 근거

- [국토교통부 2024-06-17 보도자료](https://www.molit.go.kr/USR/NEWS/m_71/dtl.jsp?id=95089865), 첨부 4–6쪽: 6월 29일 변경의 **오후 역방향 5개·가로변 전환 9개·동탄 일부 가로변 정차 6개**와 당시 ARS 번호를 확인했다. 이를 [정책 연결표](followup-policy.yaml)에 옮겼다. 노선별 정류장이 다르며 9700은 이전에도 일부 가로변에 정차했다.
- [국토교통부 2024-07-25 발표](https://www.molit.go.kr/USR/NEWS/m_71/dtl.jsp?id=95090015), 기존에 확보한 첨부: 신사→양재 중앙버스전용차로의 19시 통행시간을 **4월의 6개 관측 날짜와 7월의 6개 관측 날짜**로 비교한다. 날짜 목록은 설정에 명시했다. 2026-10-29 재확인: 5월 16일 변경은 명동 11개 노선, 강남 20개 노선 변경은 6월 29일이다. 두 지역을 묶은 발표를 강남의 두 차례 처치로 해석하면 안 된다. 단순 전후 비교만으로 다른 변화를 배제할 수는 없으며, 우리의 지수는 구간·집계·날짜가 달라 발표의 분 단위 수치를 재현하지 않는다.

2026-10-29에는 [전년·가을·기상 점검](directional-report.md)을 실제 실행했다. 노선 후보의 관측 경로 변화와 방향별 지수 차이를 확인했지만, 정류장 관측 누락과 기상 공통 표본 부족이 남았다. 아래의 당시 ID 이력·자료 정의·차량별 도착/출발 확인 우선순위는 유지한다.

## 4. 후속 수집은 무엇부터 필요한가

| 우선순위 | 자료·확인 사항 | 답할 수 있는 질문 |
|---|---|---|
| 1 | OA-21217의 시간 단위, 출발/도착 기준, 정차 포함 여부, 0의 의미, 평균 분모 | 기록 지수 감소를 실제 몇 분의 변화로 해석할 수 있는가 |
| 1 | 2024년 노선 ID 변경 이력, 특히 M7412·A/B 분리, 가로변 정류장 ID 이력 | 누가 중앙에서 가로변·북행으로 이동했는가 |
| 1 | OA-21219 빈칸 의미와 경기·인천 승차 기록의 수록 범위 | 가로변 승객이 적은 것인가, 관측이 빠진 것인가 |
| 2 | 차량별 정류장 도착·출발 시각, 배차·차량 ID, 정류장 현장 영상의 집계 자료 | 대기행렬과 정차·신호 지체를 구분할 수 있는가 |
| 2 | 검증된 기상 원본·관측 품질, 계절·방학·동시 변경 정보 | 방향별 전후 차이가 정책 외 변화에도 설명되는가 |
| 3 | 당시 승강장 위치·횡단 경로·보행 네트워크, 승객 OD·구간 재차 인원 | 버스 개선 뒤에 보행·환승 부담이 늘었는가 |

자료 정의를 해결한 뒤 원시 BMS로 대기행렬과 배차 불규칙을 측정하는 것이 이 주제의 다음 단계다. 별도 예측 모델은 이미 결과를 본 2024년 구간에서 성능을 최적화하지 않고, [후속 계획](followup-plan.md)의 새 검증·시험 기간을 사용한다. 기관·저자에게 연락하거나 데이터를 신청하지는 않았다.
