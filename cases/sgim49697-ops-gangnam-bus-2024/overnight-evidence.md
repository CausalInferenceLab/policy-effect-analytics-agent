# 10시간 확장 탐색의 자료 정의·접근성과 채택 판단

2026-10-29에 확인한 근거다. 원본 위치·해시는 [출처 명세](overnight-evidence-sources.json)에 기록하고 원본은 `data/overnight/probes/`에 보존한다. 현재 설명을 과거의 제공 조건으로 소급하거나, 논문의 필드 정의를 이 자료에 그대로 적용하지 않는다.

## 버스 자료의 실제 이용 시점

[서울시 평균 운행시간 OA-21217](https://data.seoul.go.kr/dataList/OA-21217/S/1/datasetView.do)은 날짜·시간·노선·정류장 간 평균이라는 집계 수준을 설명한다. 현재 설명은 매일 5일 전 자료를 갱신하고 Sheet/API는 최근 30일을 제공한다고 명시한다. 과거 월 ZIP의 게시일은 이 API 제공 시점과 다르다. **공개 자료로 당일 1시간 전 버스 값을 즉시 얻을 수 있다고 가정한 예측은 운영 가능성을 입증하지 못한다.** 새 실험에는 보수적인 자료 지연 시나리오를 둔다. 이 설명만으로 2024년 당시 지연도 정확히 5일이었다고 확정하지 않는다.

평균 운행시간의 초/분 단위, 출발·도착·정차 시간의 경계, 평균 분모, 0 생성 규칙은 아직 동일 자료에 적용되는 공식 근거를 확보하지 못했다. 양수 기록을 기준화한 지수를 유지한다. [구간별 총 승객수 OA-21218](https://data.seoul.go.kr/dataList/OA-21218/S/1/datasetView.do)도 현재 같은 적재 지연을 안내한다. 재차 인원 또는 완전한 승객 수로 곧바로 해석하지 않고 파일 스키마와 다른 자료의 대응부터 확인한다.

마지막 확인에서 [T Data API 1039](https://t-data.seoul.go.kr/category/dataviewopenapi.do?data_id=1039)의 `TPSS_노선_구간_속도_시간` 명세를 확보했다. `speed_XXh`, `trip_time_XXh`, `trip_fcnt`, 출발/도착 정류장 순서를 별도로 열거하고 기준일·인증키를 요구한다. 그러나 값 설명·샘플이 비어 있어 단위와 집계 경계가 해결되지는 않았다. 명칭이 비슷하다는 이유로 OA-21217과 같은 계산식이라고 확정하지 않는다. 현재 월 1회 갱신 안내도 과거 보관 범위의 증거가 아니다. 실제 API를 호출하거나 새 인증을 신청하지 않았다.

[2024-08-01 공식 서비스 중단 공지](https://data.seoul.go.kr/together/notice/datasetNoticeView.do?bbsCd=10008&ditcCd=&pageIndex=1&seq=c8c3b684c5f06d58ed26779e3ea120b8)는 8/2 21시~8/3 11시의 서버 백업과 대상 자료를 안내한다. **서비스 접속 중단과 원천 관측 중단은 다르다.** 이 시간은 주 분석의 평일 17~19시와 겹치지 않는다. 기존 [동일 노선 시간대 표](results/overnight/hour_shape/daily.csv)의 8/2 21·22시는 양방향 모두 고정 노선 관측률 100%였으므로 해당 공지를 근거로 값을 결측 처리하거나 변화 원인으로 설명하지 않았다.

[서울시 교통 데이터 제공 분류표](https://t-data.seoul.go.kr/assets/images/srvyPdf/%E2%98%85%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%A0%9C%EA%B3%B5%ED%98%84%ED%99%A9202503.pdf)는 버스 배차·위치, 신호와 C-ITS 분류를 안내한다. 구체적인 2024년 신호 주기·차량별 원기록의 공개나 보유 기간을 확인한 것은 아니다. 세 공식 문서의 로컬 원문·해시는 [후속 출처](overnight-followup-references.json)에 추가했다.

## 지역 시간별 기상: 사용 가능하나 품질과 시각을 제한해서 해석

[날씨누리 AWS 화면](https://www.weather.go.kr/w/weather/land/aws-obs.do)이 공개적으로 호출하는 JSON 응답에서 과거 시간자료를 확보했다. 2023년 4~8월, 2024년 4~10월의 서초 401·강남 400·서울 108을 요청했다. 요청과 응답의 지점·시각·간격, 각 행의 날짜 범위, 중복을 검증한다. 원본 응답은 최대 60시간이며 인접 요청 사이 12시간 이상이 겹쳐 값의 충돌도 검사한다.

[공식 도움말](https://www.weather.go.kr/wnuri_help/html/observation/aws-obs.jsp)에 따르면 `awsPcpHr1`은 선택 시각 이전 60분 강수량(mm)이다. 기온은 ℃이고 10분 풍속은 이전 10분 평균(m/s)이다. 따라서 60분 간격 조회의 모든 필드를 시간 평균이라고 부르지 않는다. 버스의 시간 표기가 구간 시작인지 끝인지 미확정이므로 −1·0·+1시간 결합을 함께 점검한다.

- 숫자 0 강수는 관측값으로 보존한다. 공란·`-`·`.`는 미관측으로 남긴다. `.`는 응답에서 확인한 비수치 표기이며 공식 QC 코드로 확정한 것이 아니다.
- 장비 장애·비장애중단은 값을 분석에서 제외하고 원본을 남긴다. `awsTroblKnd=N/A`는 정상 QC 인증으로 해석하지 않는다. 공식 역사적 QC 파일은 미확보다.
- 561개 요청 중 560개 응답을 채택했다. 강남 400의 2023-06-30 23시 요청은 22시를 반환하여 제외했다. 수집 명세에 실패를 남기고 전체 시간 격자에서 미관측을 드러낸다.
- 겹친 응답에서 14,196행을 대조했으며 측정값 충돌은 없었다. 26,424개 예정 시간 중 기온 26,246개, 1시간 강수 26,157개를 확보했다. 강수 숫자 관측률은 서울 99.56%, 강남 98.15%, 서초 99.26%다. 나머지 값을 보간하지 않는다.
- 기존 CGI 주소는 과거 요청에 현재 2026년 관측을 반환했다. HTTP 성공만으로 과거 자료라고 판정하지 않고 이 응답은 제외했다.

주 관측소는 [서초 401](https://data.kma.go.kr/tmeta/stn/selectStnDetail.do?pgmNo=82&isSelectStn=Y&stdStnNo=401)이다. 공식 상세 페이지에 2016-09-12 서초IC 이전 메모와 2023-06-09 현장 사진이 있다. 2023년 위치를 뒷받침하지만 2023~2024년 전체의 변경 이력표를 대체하지 않는다. [강남 400](https://data.kma.go.kr/tmeta/stn/selectStnDetail.do?pgmNo=82&isSelectStn=Y&stdStnNo=400)은 일원동 탄천 물재생센터에 있어 명칭만 보고 강남역 관측으로 취급하면 안 된다. 서울 108은 기존 일별 결과와 비교하는 보조 지점이다.

[기상자료개방포털 AWS](https://data.kma.go.kr/data/grnd/selectAwsRltmList.do)는 시간자료와 QC 항목을 제공하지만 내려받기에 로그인 조건이 있다. 현재 인증 없이 이용 가능한 공개 날씨 화면을 사용했으며 정식 QC 확정자료와 구분한다.

## 역사적 노선 마스터: 현재 단계에서는 보류

[T Data 노선 부가정보](https://t-data.seoul.go.kr/dataprovide/trafficdataviewfile.do?data_id=54)는 월 갱신 설명이 있지만 공개 목록에서 확인한 파일은 현재 스냅숏 한 개다. 월 갱신이라는 이유만으로 과거 월별 파일이 존재한다고 추정하지 않는다. [노선 전체 경유지 API](https://t-data.seoul.go.kr/category/dataviewopenapi.do?data_id=1058)의 신청·미리보기에는 로그인 조건이 있다.

현재 노선 이름과 과거 관측 경로를 함께 활용하되 역사적 ID↔노선명 확정 여부는 계속 미확인으로 표시한다. 정류장 ID↔ARS의 당시 대응은 기존 2023·2024년 카드 파일 대조를 유지한다. 남은 버스 노선을 무처치 대조군으로 지정하지 않는다.

## 정류장 운행 통계와 물리 환경의 후속 확인

[T Data 정류장 운행 통계 API 1083](https://t-data.seoul.go.kr/dataprovide/trafficdataviewopenapi.do?data_id=1083)는 기준일과 인증키를 요구하며 여행시간·개문/통과 누계·검출 건수 등을 명시한다. 그러나 `stpcarTimeAcmtl`의 API 설명과 [공개 파일 83](https://t-data.seoul.go.kr/dataprovide/trafficdataviewfile.do?data_id=83)의 헤더가 서로 다르고 단위·분모·시간 집계가 미확인이다. 현재 공개 파일은 첫 기간 키가 20261025여서 헤더와 기간만 확인한 뒤 중단했다. 수치 분석·전체 다운로드·2026 시험 해제는 하지 않았다. API에 날짜 인자가 있다는 이유로 2023~2025년 응답 확보를 주장하지 않는다. 상세 근거·접근 범위는 [후속 출처](overnight-followup-references.json)에 기록했다.

서울시의 [2023-11-29 조간용 원문](https://clik.nanet.go.kr/clikr-collection/policyinfo/77/313/2023/CLIKC9523951788674343_attach_2.pdf) 1~2쪽은 **2호선 강남역 양방향 중앙 승강장 연장·횡단보도 추가와 2023-11-25 개통**을, 5쪽은 공사 기간 2023-10-17~11-25를 명시한다. 2024-02-27 소개 영상의 게시일과 실제 개통일을 구별했다. 이 원문만으로 ARS별 길이·검지 경계·신호 주기까지 확인한 것은 아니다. 2023년과 2024년의 정류장 환경 동일성을 가정하지 않으며, 2024년 6월 버스 조정의 직접 동시 사건으로도 분류하지 않는다. 원문은 로컬에 보존하고 해시만 공개했다.
