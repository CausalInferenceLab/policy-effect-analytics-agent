# 2025년 미열람 구간으로 점검할 저속 경보·예측구간 계획

2026-10-29 02:10 KST 전후, 2025년 속도 원본을 수집·열람하기 전에 작성했다. 기존 2024년 결과를 이미 보았으므로 전체 연구의 사전 등록은 아니다. 새 2025년 시험값에 대한 평가 규칙은 이 문서와 [설정](overnight_forecast_config.yaml)에 먼저 고정한다. 2026년 잠금 시험값은 계속 접근하지 않는다.

## 질문과 자료

일반도로 속도의 평균 오차뿐 아니라 **다음 1·3시간에 시속 10km 미만인 상황을 어느 정도 찾아내고, 거짓 경보는 얼마나 발생하는가**를 묻는다. 10km/h는 이 실험의 선택 기준이며 공식 혼잡 등급이라고 주장하지 않는다. 각 링크의 학습기 속도 하위 20%를 상대 기준으로 함께 점검한다. 버스 운행시간 자료와 다른 측정 대상이며 버스 승객의 도착시간 경보로 부르지 않는다.

기존 강남대로 핵심 3개 링크를 주 평가 대상으로 유지하고 강남대로·사평대로·테헤란로·봉은사로·서초대로의 링크를 학습에 쓴다. 링크의 채택과 상대 저속 기준은 2023~2024년 학습 자료만으로 정한다. 학습기 관측률 95%와 시종점·방향·길이 일관성을 요구한다. 이후 속성 변경은 해당 기간 제외·보고로 처리하며 시험 점수를 보고 링크를 바꾸지 않는다.

| 역할 | 기간 | 허용하는 판단 |
|---|---|---|

겨울 선택·봄 보정에서 여름 시험으로 넘어가므로 계절 이동 자체가 평가 난점이다. 모델·특징·보정기·경보 임계값의 해시를 먼저 동결한 뒤 시험 월의 속도 파일을 수집한다. 시험 결과로 튜닝하지 않는다. 시험 전 실패로 규약을 바꿀 필요가 있으면 이유와 시각을 기록하고 다시 고정한다.

## 자료가 실제 언제 보이는가

[서울시 버스 운행시간 설명](https://data.seoul.go.kr/dataList/OA-21217/S/1/datasetView.do)은 현재 5일 전 자료를 갱신한다고 안내한다. 버스 보조 특징은 적어도 7일 이전 자료만 사용한다. 월 ZIP이 당시 7일 내 게시되었다는 뜻은 아니며, 현재 API 제공 조건을 고려한 보수적 회고 시나리오다.

도로는 [실시간 소통 API](https://data.seoul.go.kr/dataList/datasetView.do?currentPageNo=1&infId=OA-13291&serviceKind=1&srvType=A)가 별도로 존재하지만 과거 파일의 각 값이 당시 언제 확정되었는지는 확인하지 못했다. 따라서 달력만, 7일 이전 속도, 한 시간의 처리 여유를 둔 최근 도로 관측 가정을 나누어 성능을 비교한다. 마지막 시나리오도 운영 환경 검증은 아니다. 실제 미래 날씨를 예보처럼 넣지 않는다. 주 분석 모델의 기상 특징은 제외한다.

정시 `t`에 예측할 때, 최근 도로 특징의 가장 늦은 시간 구간은 `t−2`에 시작해 `t−1`에 끝난다. 1시간 예측 목표는 `t`에 시작하는 시간, 3시간 목표는 `t+2`에 시작하는 시간이다. 서로 다른 시점을 행 단위 지연으로 착각하지 않도록 실제 시각으로 결합하고 검사한다. 목표값은 보간하지 않는다.

## 모델과 평가

요일·시간·링크별 계절 확률, 로지스틱, CatBoost 분류기를 비교한다. 불균형 보정 가중치를 자동 적용하지 않고 확률 보정과 경보 기준을 분리한다. CatBoost 분위수 모델로 10·50·90% 예측값도 만든다. [공식 손실 문서](https://catboost.ai/docs/en/concepts/loss-functions-regression)를 기준으로 분위수별 pinball, 80% 구간의 실제 포함률·폭·교차율을 평가한다. 후보 수와 최대 학습 행 수·시드는 설정에 고정한다.

주 지표는 핵심 3개 링크의 average precision이다. Brier·log loss·실제 저속 비율과 경보 정밀도·재현율·거짓 양성률·하루 경보 수를 같이 제시한다. 전체 시간, 저녁, 개별 링크, 월별 결과와 주 단위 재표집 불확실성을 보고한다. 성능이 개선되지 않아도 보류·실패 이유와 기준선 결과를 남긴다.
