# 강남대로 버스 분산 이후의 관찰과 예측 결과

이 문서는 현재 프로젝트의 결과 진입점이다. 정책 배경부터 데이터·분석·활용까지는 **[프로젝트 설명 HTML](project-overview.html)**, 상세 비교는 [종합 보고서](deepening-summary.md)를 따른다. 초기 일반도로·GPU 모델 실험은 [이전 버전 안내](archive.md#reports)에서 구분해 읽는다.

## 질문과 데이터

2024년 6월 29일 광역버스 분산 이후 강남대로에서 관찰되는 변화가 방향에 따라 다른지, 다른 운영 변화와도 함께 나타나는지 살펴봤다. 정책의 인과효과는 `not_identified`(판단 불가)다.

| 자료 | 분석에서 맡은 역할 | 해석할 때 필요한 구분 |
|---|---|---|
| 서울 버스 정류장 간 소통·운행 기록, 2023~2025년 32개월 | 방향·노선·시간대별 기록과 관측 가능성 비교 | 시간 필드의 단위·정차 범위 미확정 |
| TOPIS 일반도로 속도, 2023~2025년 36개월 | 주변 도로 변화와 별도 속도 예측 | 버스 통행시간과 다른 관측량 |
| 역사 노선·정류장 목록과 공식 정책·개통 안내 | ID 대응, 542번 폐선, 2025년 새 정류소 운영 확인 | 목록의 시간 공백과 개별 차량 이력 부재 |
| 기상 기록과 월별 파일 목록 | 기상에 따른 비교 범위, 예측 입력의 공개 지연 확인 | 기상은 넓은 보조 표본, 공개 시각은 보존된 목록에 근거한 가정 |

## 비교 방법과 관찰

사전 창은 5월 20일~6월 28일, 사후 창은 7월 8일~8월 16일의 평일·비공휴일이다. 사전 공동 관측 규칙으로 선택한 14개 노선에서 폐선 542번을 제외한 13개를 비교했다. 시간대별 값을 사전 기준으로 정규화한 뒤 노선·날짜를 동일 가중으로 집계하고 저녁 17~19시를 요약했다. 두 방향은 정확히 뒤집은 동일 물리 구간이 아니다.

| 관찰 | 결과 | 의미 |
|---|---|---|
| 정책 후보로 연결한 현재 ID 20개의 남행 중앙 정류소군 기록 | 원본 날짜가 있는 날의 양수 기록 비율 94.4% → 25.2% | 이동 설계와 부합하는 관측이지만 기록 부재의 원인을 직접 확인하지 못함 |
| 별도 고정 서울버스 13개의 핵심 두 구간, 2024년 여름 | 남행 −49.71%, 북행 +41.03% | 정규화 시간 기록 지수의 반대 변화 |
| 같은 고정 집단, 2024년 사전 대비 2025년 여름 | 남행 −46.02%, 북행 +40.95% | 다음 해에도 수준 차이가 남음 |
| 2025년 새 중앙 정류소 운영 | 중앙 안내군 7개 노선×4개 정류소의 28개 조합에서 1월 11일 첫 양수 기록 | 2024년 분산 정책과 구분되는 별도 운영 변화 |

정책 후보 20개와 고정 13개를 같은 집단으로 합치지 않는다. 변화율은 실제 이동시간의 분 단위 절감량이 아니다. 주변 도로의 시행일 전 하락과 회귀 설정에 따른 차이도 있어 단일 정책 원인을 확정하지 않는다. [집단별 기록 비율](results/deepening/review/record_support.csv), [고정 노선 비교](results/deepening/cohort/comparisons.csv)

## 별도 실험: 공개 과거 월로 속도 예측

학습에는 62개 링크의 2023~2024년, 튜닝에는 2025년 1~2월을 사용했다. 평가는 강남역 남행 핵심 3개 링크의 2025년 여름·가을·겨울 구간이다. 공개 지연을 고려해 달력만 쓰는 조건과 공개된 과거 월 속도를 추가하는 조건을 비교했다. 입력 2개×발행 시점 2개×시드 2개의 CPU CatBoost 모형 8개를 학습했다.

시드 17의 H1 예측에서 과거 월 입력은 같은 조건의 달력 모형보다 MAE를 여름 **29.29%**, 가을 **21.26%** 낮췄다. 단순 최근 3개월 기준선 대비 개선은 각각 **8.43%**, **11.52%**였다. 목표 80% 예측구간의 12월 포괄률은 과거 월 모형 **74.10%**, 달력 모형 **83.56%**였다. 평균 오차 개선과 구간의 신뢰성은 별도로 평가한다.

2025년 결과를 이미 본 뒤 수행한 후속 탐색이다. 실제 운영 성능이나 정책의 반사실 효과를 추정한 값으로 해석하지 않는다. [학습·평가 설명](deepening-archive-report.md), [전체 성능표](results/deepening/archive_forecast/metrics.csv), [짝 비교](results/deepening/archive_forecast/paired_comparisons.csv)
