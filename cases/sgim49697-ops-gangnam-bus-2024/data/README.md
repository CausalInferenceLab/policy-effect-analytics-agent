# 로컬 원자료와 가공 자료

이 폴더의 데이터는 Git에 넣지 않는다. 월별 원본은 `raw/`, 메타데이터는 `metadata/`, 정규화 자료는 `processed/`, 기상은 `weather/`, 역사적 연결표는 `graph/`에 둔다. 공개하는 파일 식별·해시 기록은 사례 루트의 `source-manifest.json`이다.

2026-10-28에는 2023-01~2024-08 원본 XLSX 20개와 메타데이터만 확보했다. 실제 속도 집계·정규화 Parquet·정책 패널은 아직 만들지 않았다. 원본 수집은 이용허락 확인이나 측정 정의 검증을 대신하지 않는다.

`fetch.py`는 캐시가 있으면 원격 목록 항목과 파일 해시를 확인한다. 해시가 달라지거나 출처 기록 없이 원본만 있으면 덮어쓰지 않고 중단한다. 중단된 `.tmp` 다운로드는 재실행 시 새로 받는다. 월별 파싱 중 오류가 나도 정상 다운로드한 원본은 보존한다.
