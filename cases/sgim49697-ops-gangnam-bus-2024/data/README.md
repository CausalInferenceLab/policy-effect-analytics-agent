확인 상태는 이 사례에 보존된 근거를 기준으로 적었다. 공개 열람·다운로드 가능 여부를 재배포 허가로 간주하지 않는다. PR 체크리스트에도 이용 조건의 미확인 범위를 남기며, 이번 제출 보완에서 원본 이용허락을 새로 확정했다고 표시하지 않는다.

## 정규화와 해석

버스 ZIP의 CP949 헤더·첫 행 폭을 대조하고 열이 어긋난 멤버는 격리한다. 원본의 0·음수·공란을 보존한 뒤 최종 지수에는 양수 공동 관측만 사용한다. 월 경계에서 값이 같은 중복은 제거하고 값이 다른 키는 모두 격리한다. 같은 노선이 정류장 쌍을 반복 방문한 행도 제외한다.

도로 `~01시`는 00:00–01:00 구간이며 `~24시`는 같은 날짜의 23:00–24:00이다. 빈 셀·0·음수·문자열 `NULL`은 탐색 분석의 결측 처리 가정이다. 링크×시간 격자를 보존하며 월별 속성이 달라지거나 없으면 그 링크의 해당 월 전체를 마스킹한다.

`cache` 항목은 기존 로컬 정규화 파일을 재사용할 때만 필요하다. 없는 경우 원본에서 직접 파싱한다. 오래된 `results/*/extraction_audit.json`을 요구하지 않는다. 새 파일은 `runs/<ID>/`에 기록한다. 기존 `data/`, `runs/`, `.cache/`, `.venv/`는 정리 중 보존했다.

버스의 '운행시간' 값은 물리 단위가 확인되지 않아 초·분으로 바꾸지 않는다. 도로 속도는 km/h다. 도로 게시·수정일은 현재 파일의 공개 가능 시각에 대한 대리값이며 당시 파일 버전이 같았다는 증거는 아니다.
