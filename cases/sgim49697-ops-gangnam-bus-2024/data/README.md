# 로컬 원자료와 가공 자료

이 폴더의 데이터는 Git에 넣지 않는다. 월별 원본은 `raw/`, 메타데이터는 `metadata/`, 정규화 자료는 `processed/`, 기상은 `weather/`, 메타데이터로 유도한 연결표는 `graph/`에 둔다. 공개하는 파일 식별·해시 기록은 사례 루트의 `source-manifest.json`이다.

2026-10-28에 2023-01~2024-08 XLSX 20개를 정규화했다. `processed/`에 월별 Parquet와 무결성 정보, `audit.json`에 90개 링크·1,315,440행의 결측과 시간 창, `graph/`에 82개 방향 연결과 미검증 가정의 근거를 남겼다. 정책 비교와 예측 결과는 `../runs/`에 보관하고 공개 집계만 `../results/`에 복사한다. 원본 수집은 이용허락 확인이나 측정 정의 검증을 대신하지 않는다.

`fetch.py`는 캐시가 있으면 원격 목록 항목과 파일 해시를 확인한다. 해시가 달라지거나 출처 기록 없이 원본만 있으면 덮어쓰지 않고 중단한다. 중단된 `.tmp` 다운로드는 재실행 시 새로 받는다. 월별 파싱 중 오류가 나도 정상 다운로드한 원본은 보존한다.

## 10시간 확장 탐색

`overnight/`에 지역 기상 응답, 버스·카드·지하철·도로 원본, 선택 패널, 모델·개별 예측을 별도 보존한다. 모두 Git 제외 대상이며 공개 근거는 사례 루트의 `overnight-*-sources.json`, 파생 집계·자체 그림은 `../results/overnight/`에 있다. 실패 응답·손상 주간·결측을 정상 자료로 바꾸거나 자동 삭제하지 않는다.

`overnight/confirmation/`은 최초 열람 전에 별도 후보를 동결한 2025년 9~12월 도로 검증이다. 원래 2025년 5~8월 시험을 덮어쓰지 않는다. 2026년 수치는 분석·학습에 사용하지 않았다. 현재 스냅숏 파일의 접근성을 점검할 때는 헤더와 기간 키만 확인해 과거 자료가 아님을 기록하고 중단했다. 원본·모델 없는 공개 복제본의 검증은 [재현 안내](../overnight-reproduction.md)를 따른다.
## 추가 조사 원본 보관

2026-10-28 후속 조사의 버스·교통량·마스터·정책 발표 원본은 `discovery/`에 보관하며 Git에서 제외한다. 고정 요청·해시는 [추가 수집 명세](../discovery-sources.json), 자료별 범위와 한계는 [후속 계획](../archive.md#reports) (`followup-plan.md`, 로컬 보관)에 있다. `discover.py collect`로 고정 원본을 확인·수집하고, `audit`는 지정 주간과 교통량 결합을 점검한다. 새 파일이 기존 해시와 다르면 덮어쓰지 않는다. 조회 시점의 노선·정류장 마스터를 2024년 역사적 설명표로 취급하지 않는다.
