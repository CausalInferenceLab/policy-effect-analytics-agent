# 자료 정의와 메타데이터 확인 기록

확인일: 2026-10-28. 이 문서는 속도 효과나 모델 성능을 분석한 결과가 아니라 수집 가능성과 자료 구조를 확인한 기록이다. 외부 AI 답변은 원문 그대로 별도 보존하며, 그 안의 주장을 자동으로 확인된 사실로 옮기지 않았다.

## 실제 다운로드와 메타데이터

[TOPIS 도로별 일자별 통행속도](https://topis.seoul.go.kr/refRoom/openRefRoom_1.do)의 2023-01~2024-08 월별 XLSX 20개를 내려받았다. 총 712,259,748 bytes다. ZIP 구조·CRC·헤더·선택 도로의 링크×일자 중복을 확인했다. 개별 파일의 조회 인자·크기·SHA-256은 [source-manifest.json](source-manifest.json)에 기록했다. 원본과 개별 행 자료는 Git에서 제외한다.

- 강남대로·동작대로·송파대로·시흥대로에서 매월 94개 링크가 확인됐다. 각 월의 링크×일자 수는 `94 × 그달의 날짜 수`였다. 이는 속도값이 모두 유효하다는 뜻이 아니다.
- **시간 헤더 변경:** 2023-01~2024-02는 `01시`~`24시`, 2024-03~08은 `~01시`~`~24시`. 두 표기 모두 종료시각인지 공식 정의가 필요하다. 현재 파서는 알려진 두 헤더를 구분해 보존하며 미확인 형식은 거부한다.
- **속성 변경:** 전체 20개월에서 50개 링크의 메타데이터가 달랐다. 차선 수 변경 링크 49개, 시점명 변경 링크 2개, 종점명 변경 링크 2개이며 서로 중복된다.
- **핵심 처치 링크:** `1220025000`, `1220021000`, `1220016200`의 차선 수가 2023-01~03에는 4, 2023-04부터는 5로 기록됐다. 거리·시종점·방향은 이 비교에서 같았다. 도로 확장, 집계 기준 변경, 속성 정비 중 어떤 이유인지 아직 확인하지 못했다.
- **이름 변경:** 강남대로의 `1210007600`, `1210007700`, `1210008400`, `1210008500`에서 `aT센터`와 `국악고교입구`가 시점 또는 종점명으로 바뀌어 기록됐다. 이름만 바뀐 것인지 실제 구간이 바뀐 것인지 지도와 대조해야 한다.
- **정책 수집 구간:** 2024-04~08 안에서는 선택한 94개 링크의 메타데이터가 같았다. 따라서 2023년부터의 ML 연결 문제와 2024년 정책 분석의 측정 확인을 구분해야 한다.
- 송파대로 석촌역→가락시장역은 남쪽 방향이지만 TOPIS 표기는 `상행`이다. 도로 사이에서 같은 방향 문자열을 그대로 적용하지 않았다.

## 정책과 보고서의 확인 범위

[서울시 2024-06-18 안내](https://mediahub.seoul.go.kr/archives/2011484)는 6월 29일 강남 방향 20개 노선 조정을 설명한다. 5개 노선의 오후 운행 방향 변경과 15개 노선의 가로변 이용·정류장 조정이 섞인 정책이다. 모든 노선에 같은 시간대 조치가 적용됐다고 단정하지 않는다. 명동 방향 2개 노선은 제외한다.

[2024년 차량통행속도 보고서 게시 페이지](https://news.seoul.go.kr/traffic/archives/417)의 [원본 PDF](https://news.seoul.go.kr/traffic/files/2012/02/67dd1036f021f2.16441564.pdf)를 직접 내려받아 확인했다. 총 622페이지이며 PDF 26쪽(책자 2쪽)은 영업용 택시 위치정보를 통한 승용차 통행속도 산출, PDF 29쪽(책자 5쪽)은 속도 종류·시간대 정의를 설명한다. 보고서의 오후 구분은 17~19시다. 이 프로젝트의 17~20시는 연구 설계 선택이며 보고서 기준과 같다고 주장하지 않는다. 이 페이지들만으로 월별 파일의 0 값·시간 헤더·개별 자료 이용허락을 확정하지 않았다.

[서초구의회 2024-11-19 보고](https://sdc.seoul.kr/main/minutes/html/MinutesView.do?MINTS_SN=5089)에 양재천 우안도로의 6월 29일 공사완료가 기록돼 있다. 실제 개통 시각과 우회 파급은 별도 확인한다. 동시 장마·기후동행카드 변화는 외부 문서의 링크를 출발점으로 추가 대조한다.

## 공휴일과 기상

공휴일은 `holidays==0.107`의 한국 공휴일을 사용한다. 연간 발표 이후 추가된 휴일도 점검한다.

2023·2024 역서의 각 PDF 9쪽과 아래 추가 공고를 대조했다. 2023년 18개, 2024년 1~8월 12개 날짜가 패키지 결과와 일치했다. 확인한 날짜 목록을 `data_contract.yaml`에 고정하고 실행 시 다시 비교한다. 일요일·토요일은 별도 요일 조건으로 처리하며 7월 17일 제헌절은 공휴일로 넣지 않는다.

- [2023년 월력요항 발표](https://www.kasi.re.kr/kor/publication/post/newsMaterial/29168), [2023년 역서](https://astro.kasi.re.kr/file/astro_almanac_pdf/20221209095149975.pdf).
- [2023-05-29 대체공휴일 안내](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?cntId=3625&mode=view).
- [2023-10-02 임시공휴일 지정 공고](https://www.mpm.go.kr/mpm/comm/noti/mpmNotice/?boardId=bbs_0000000000000205&cntId=719&mode=view).
- [2024년 월력요항 발표](https://www.kasi.re.kr/kor/publication/post/newsMaterial/29633), [2024년 역서](https://astro.kasi.re.kr/file/astro_almanac_pdf/20231023135218580.pdf). 4월 10일 국회의원 선거일을 포함한다.

기상은 [기상청 ASOS 일자료](https://www.data.go.kr/data/15057210/openapi.do)의 서울 108번 지점을 사용한다. 현재 기상 파일은 확보하지 않았다. 공식 다운로드 CSV를 등록하는 경로를 구현했고, 강수량 빈칸을 0으로 바꿀 때도 정의 근거를 요구한다. 미래 실제 날씨를 예측 입력으로 넣지 않는다.

## 남아 있는 실행 관문

1. 두 시간 헤더 형식의 구간 정의, 0·음수·특수 결측, 월별 파일의 속도 단위.
2. 월별 원자료의 이용 조건과 집계표·그림 공개 가능 범위.
3. 2023년 차선 수·지점명 변경의 원인, 택시 표본·속도 보정 방식의 연속성.
4. 당시 지도·노선으로 확인한 처치 범위와 비교 도로의 비노출·공사 이력.
5. 그래프 모델에 사용할 2023~2024 유효 연결표. [공개 보간점 자료](https://data.seoul.go.kr/dataList/OA-15060/F/1/datasetView.do)의 2022·2025 파일만으로 중간 연도를 확정하지 않는다.

각 항목을 해소하면 `data_contract.yaml` 또는 `corridors.yaml`에 출처·판단을 기록하고 다시 커밋한다. 설정을 바꾸면 24시간 관문도 해당 커밋 기준으로 다시 계산한다.
