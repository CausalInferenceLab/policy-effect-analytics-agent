# 외부 조사·기관 확인에 사용할 후속 요청서

현재 구현 과정에서 새로 발견한 자료 차이를 해결하기 위한 요청서다. **아직 기관에 발송하지 않았다.** 아래 내용을 외부 AI에 전달할 때는 공식 원문 URL·문서 페이지·해당 자료에 적용되는 이유를 함께 요청한다. 찾지 못한 사실은 미확인으로 남기며 그럴듯한 일반론으로 대체하지 않는다.

## 2026-10-29 확장 분석 이후의 우선 요청

2023년 1월~2025년 8월 버스 기록을 살펴본 결과, 강남역 주변의 남행 22011→22009와 북행 22008→22010은 2024년 7월 초 이후 서로 반대 방향의 기록 변화가 이어진다. 같은 노선의 인접 구간 합과 16시간 공동 표본에서도 차이가 남는다. [종합 결과](overnight-summary.md)와 [자료 정의 기록](overnight-evidence.md)을 먼저 참고해 달라. 이는 특정 원인을 확인한 결과가 아니며 다음 빈칸을 해결하려는 요청이다.

답변은 아래 형식을 사용해 달라. ‘접근 가능’은 실제 과거 응답이나 명시적 보관 범위가 확인된 경우에만 적고, 인증 필요·신청 필요·미확보를 구분한다. 문의/신청 문안을 제안할 수 있지만 기관 연락·계정 생성·자료 신청·결제는 수행하지 않는다. 특정 정책 효과를 강화할 목적으로 비교 기간·노선·정류장을 고르는 제안은 원하지 않는다.

## 최초 일반도로 분석에서 남아 있는 질문

서울 TOPIS의 2023년 1월~2024년 8월 「서울시 차량통행속도」 월별 XLSX 20개를 수집했다. 2024년 6월 29일 강남대로 광역버스 분산 전후 일반도로 속도를 비교하고, 별도로 과거 168시간으로 다음 1·3시간 속도를 예측하는 학생 프로젝트다.

자료 페이지: https://topis.seoul.go.kr/refRoom/openRefRoom_1.do

정책 안내: https://mediahub.seoul.go.kr/archives/2011484

## 우선 확인할 질문

1. **시간 열:** 2023-01~2024-02 파일은 `01시`~`24시`, 2024-03 이후는 `~01시`~`~24시`다. 각각 당일 00~01시와 23~24시를 뜻하는가? 표기만 바뀌었는가, 집계 구간도 바뀌었는가? 시간대는 한국 표준시인가?
2. **결측과 단위:** 0, 음수, 빈칸, 특수 기호는 각각 무엇인가? 0이 유효한 완전 정체인지 미수집 코드인지 구분할 수 있는가? 속도는 km/h, 거리는 m인가? 원자료의 평활·보간·표본 부족 처리 규칙은 무엇인가?
3. **2023년 속성 변경:** 핵심 링크 `1220025000`, `1220021000`, `1220016200`의 차선 수가 2023년 1~3월에는 4, 4월부터는 5로 기록된다. 실제 차로 변화인가, 버스전용차로 포함 여부 등 메타데이터 정비인가? 해당 시점의 자료 생성 방식·택시 표본도 달라졌는가?
4. **지점 이름 변경:** `1210007600`, `1210007700`, `1210008400`, `1210008500`의 시점/종점에 `aT센터`와 `국악고교입구`가 달리 기록된다. 같은 경계의 명칭 변경인가? 당시 형상·노드·변경 이력으로 확인 가능한가?
5. **이용 조건:** 이 월별 XLSX의 연구 이용, 가공 지표·집계 그림 공개, 재현용 다운로드 코드 공유에 적용되는 이용허락은 무엇인가? 구별 통계나 지도 자료의 공공누리를 월별 속도 원자료에 전용하지 말고 해당 자료의 조건을 확인해 달라.
6. **역사적 공간·정책 노출:** 교보타워사거리→뱅뱅사거리의 3개 하행 링크가 2024년 조정 대상과 어떻게 겹치는가? 동작대로 이수역→사당역, 송파대로 석촌역→가락시장역, 시흥대로 구로디지털단지역→시흥IC에서 당시 관련 노선·우회·공사·신호 변경이 있었는가?
7. **동시 변화:** 양재천 우안도로의 2024-06-29 공사완료와 실제 개통을 구분해 구간·시각·연결도로를 확인해 달라. 장마와 7월 1일 기후동행카드 변화도 도로별 영향 가능성을 검토해 달라.
8. **그래프:** 2023-01~2024-08 전체에 유효한 서비스링크 연결표나 버전 이력이 공개돼 있는가? 2022·2025 형상만으로 유효성을 추정하지 말아 달라.

## 답변 형식

| 질문 | 확인된 답 | 공식 URL·문서 페이지 | 적용 연도·자료 | 남은 불확실성 |
|---|---|---|---|---|

공식 문서를 못 찾았다면 문의할 담당 부서와 물어볼 내용을 제안해 달라. 기관에 연락하거나 자료를 신청하는 행동은 이 요청서에 포함하지 않는다. 유리한 정책 효과나 모델 점수를 얻도록 기간·비교군을 바꾸는 제안은 필요하지 않다.
