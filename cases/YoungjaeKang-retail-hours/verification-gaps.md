# 공개 자료의 정책 확인 공백

작성일: 2026-10-12. 최근 보완: 2026-10-13. [선정 기준](plan.md#비교군-선정-기준--전수-조사-전에-정할-사항)과 [확인한 근거](policy-verification.md)를 연결해 남은 작업을 특정한다. 공개 고시·구보·공식 안내에서 확인할 항목을 정리한 조사 작업표다. 기관 직접 문의·정보공개청구·회신 대기는 작업 범위에 포함하지 않는다.

## 현재 판단

20개 비교 후보 중 2021~2024 전체 정책 이력 확인을 마친 구는 **0개**다. 개별 시점의 규칙·한시 변경·규제 제외 자료는 확보했지만, 기간 시작의 유효 처분과 기간 내 변경·대상 점포를 연결하지 못했다. 따라서 아직 기본 비교군을 확정할 수 없다. 자료 미확보는 정책 미시행 또는 구의 비교 부적격을 뜻하지 않는다.

원문이 필요한 공백을 남긴 채 동일한 웹 검색을 반복하지 않는다. 아래에 특정한 처분·첨부·대장을 공개 게시판과 구보에서 확인하고, 확보하지 못한 항목은 출처·검색 범위와 함께 미확인으로 남긴다. 공개 자료로 판단할 수 있는 범위에서 다음 단계를 진행하며, 검색 실패를 정책 미시행의 근거로 삼지 않는다.

## 모든 구에 공통으로 필요한 문서

1. **2021-01-01 현재 유효한 기본 처분:** 휴업 요일·영업제한 시간·효력일·대상 점포를 명시한 고시와 별표. 이전에 발령됐더라도 해당 시점에 유효한 공개 문서를 확인한다.
2. **2021-01-01~2024-12-31 변경 이력:** 정기 요일 변경, 한시 대체, 지정 해제·규제 제외·복원 및 신규 점포 적용 처분. 발표·고시·효력일을 구분한다. 공개 문서가 변경 없음을 명시한다면 그 문서가 다루는 기간·대상과 근거를 기록한다.
3. **대상 점포 대장:** 점포명·소재지·대형마트/SSM 구분·규제 적용 상태와 시작/종료일. 해당 기간 개폐점·명칭 변경으로 점포를 연결할 수 있는 자료. 개점일을 등록일로 대신하지 않는다.
4. **전환 발표·협약과 연계 지원:** 구체적 대상·일정이 있는 발표 또는 협약, 관련 지원사업 대상·실제 집행 시점. 단순 논의와 확정 발표를 구분한다.

## 공개 자료 확인 후의 처리와 다음 단계

공개 문서마다 출처·문서번호·대상 기간·점포·확인한 내용·남은 공백을 기록한다. 현재 안내만으로 과거 전체 기간을 채우지 않는다.

정책 적격성이 확인된 후보와 보류 후보를 구분한 뒤, 사전 특성표와 공간·동시 변화 근거를 함께 검토한다. 최종 비교 명단과 이유를 매출 열람 전에 커밋·PR한다. 현재 조사 기준·진행 기록을 검토용 PR로 남기는 것과 최종 명단 확정은 별개다. 정책 이력이 부족하면 확인된 범위를 넘는 인과판정을 진행하지 않는다.

정책 확인과 별개로 진행할 수 있는 다음 작업은 인구·가구·점포·시장 특성의 수집 경로 구현이다. 원자료 수집 전 계획을 커밋·PR하는 절차를 먼저 충족한다. API 키는 경로상 필요한 서비스가 확정될 때 설정한다.


## 이번 보강에서 해결한 공백과 이월 항목

2026-10-13에 동대문 2024-121호 첨부를 확보해 대상 별표 미확인을 해소했다. [점포 목록과 날짜](policy-verification.md#2024-121호-첨부-대상-목록-확인--2026-10-13)는 정책 확인표에 기록했다. 남은 공개 자료 확인 항목은 다음과 같다.

- 동대문: 경동시장점의 2023년 한시 변경 제외가 단순 일정 제외인지 별도 규칙 때문인지, 2024년 대상 포함까지 어떤 처분이 적용됐는지 확인할 문서. 2014-86호는 고시번호 검색에서 확보하지 못해 과거 구보의 공개 자료 확인 항목으로 남긴다.
- 강북: 2020-38호 페이지 재조회에서도 원첨부를 확보하지 못했다. 해제 효력일과 각 유지 심사의 적용 기간·공백을 특정할 공개 첨부 및 대장을 추가 확인 항목으로 남긴다.
- 성동: 협약 예정 보도와 실제 체결 문서를 구분한다. 행당역점의 규제 미적용 보도에 대응하는 처분·분류 근거와 이후 변경을 공개 자료에서 확인한다.
- 용산: 기존 2개 점포의 규제 제외 시작·종료 처분을 공개 자료 확인 항목으로 남긴다. 현재 제공 설명만으로 기간 내 연속성을 채우지 않는다.

같은 검색을 반복하기보다 확보 경로가 특정되지 않은 항목은 이 목록에 남기고 [특성자료 수집 계획](collection-plan.md)에 따른 코드 준비를 병행한다. 기관 회신을 진행 조건으로 두지 않는다. 다만 정책 미확인을 해소한 것으로 취급하지 않으며, 근거가 부족하면 최종 비교군 편입과 인과효과 판단을 보류한다.
