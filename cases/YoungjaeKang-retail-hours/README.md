# 대형마트 의무휴업 평일 전환과 골목상권 매출

작성자: 강영재 (`YoungjaeKang`)

동대문구의 대형마트가 일요일 대신 평일에 쉬게 된 뒤 골목상권의 식품판매 매출이 어떻게 달라졌는지 살펴본다. 서울의 다른 자치구와 비교하고, 자료 수집부터 검사·분석·보고서 작성까지 이어서 실행할 수 있도록 만드는 것이 7주 과정의 목표다.

| 항목 | 내용 |
|---|---|
| 처치 | 동대문구, 분석상 시작 분기 2024Q2 |
| 비교 | 서울 내 20개 자치구 고정 — 공개 근거와 점포 이력 공백을 명시한 탐색 비교 |
| 기간 | 2021Q1~2024Q4, 2024Q1만 추정에서 제외 (원자료·전체 분기 집계에는 보관) |
| 지표 | 골목상권 육류·수산물·청과·반찬 판매 추정매출 합계의 자연로그 |
| 방법 | 이벤트스터디, 가짜 시행일 검정 |

공개 자료로 정책 근거·집계·검사·추정 과정을 재현할 수 있는 사례를 만드는 데 초점을 둔다. 효과의 유의성보다 근거와 해석 범위를 분명히 남기는 것을 완료 기준으로 삼는다.

분석 범위와 일정은 [plan.md](plan.md), 실행 설정은 [plan.yaml](plan.yaml)에서 볼 수 있다. 자치구별로 찾아본 근거와 더 확인할 내용은 [정책 확인표](policy-verification.md)에 모았다.

서울 25개 구의 [공통 조사표](comparison-survey.md)와 [자료원·지표 정의](data-notes.md)를 마련했다. [특성자료 수집·검사 계획](collection-plan.md)에 2022년 자료의 조회 조건·누락 처리·보류 조건·로컬 산출물을 정했다. 가구·면적·인구와 시장 일부를 수집·검사했으며 점포 집계는 보류한다. 비교군 20개 구는 [선정 근거](control-review.md)와 [명단](comparison-groups.yaml)에 고정했다. [구별 공개 자료 확인 공백](verification-gaps.md)에 다음에 확보할 문서를 특정했다.

선행연구의 질문·방법·한계와 사례에 적용할 내용은 [연구 노트](research-notes.md)에 정리했다.

초기 계획은 [PR #9](https://github.com/CausalInferenceLab/policy-effect-analytics-agent/pull/9)로 main에 병합됐고, 선행연구·분기 처리 보완 [PR #10](https://github.com/CausalInferenceLab/policy-effect-analytics-agent/pull/10)과 비교군 조사 [PR #11](https://github.com/CausalInferenceLab/policy-effect-analytics-agent/pull/11)은 2026-10-15 병합됐다. 매출 원자료는 아직 수집하거나 분석하지 않았다. 비교군 정책 이력, 동시기 지원사업, 자료 기준을 확인하고 필요한 계획 보완을 커밋·PR에 반영한 뒤 수집 코드(`fetch.py`)와 이 사례에 필요한 검사를 작성할 예정이다. 점포별 예외 전수 확인은 완료 조건에서 제외했다. 정책 오분류·동시 정책·공간 파급의 한계를 명시한 탐색 분석으로 진행하며 순수 인과효과 판단은 보류한다. 매출·공간 버전 호환성 검사는 후속 수집의 필수 조건이다.

## 현재 결과

특성자료 수집·검사 구현과 재현 방법은 별도 [PR #22](https://github.com/CausalInferenceLab/policy-effect-analytics-agent/pull/22)에서 리뷰 중이다. 이번 PR에는 해당 구현을 포함하지 않는다.

2026-10-13 로컬 취득·검사에서 500개 값 중 222개를 확인하고 278개를 보류했다. 인구·가구·연간 면적은 25개 구, 시장 개수는 22개 구, 시장 존재 여부는 25개 구에서 확인했다. 인구밀도는 면적 기준일, 종로·은평·영등포 시장 수는 동일 주소 후보의 독립성, 점포 집계는 공간 버전과 행 부재의 의미가 미확인이라 보류한다. 수집 코드·세부 검사 기록은 #22에서 확인할 수 있다.

이 특성자료는 지역 차이를 설명하는 데 사용하며 비교군 자동 매칭이나 효과 추정 결과가 아니다. 원자료·가공 값·개인 메모는 Git에 포함하지 않는다.

## 비교군 확정 (2026-10-20)

[구별 근거와 한계](control-review.md)를 반영해 처치 1개·비교 20개·제외 3개·보류 1개를 고정했다. [명단 원본](comparison-groups.yaml)과 plan.yaml의 목록이 일치한다. 점포별 예외 전수 확인을 완료 조건에서 제외했으며 미전환이 입증된 명단으로 해석하지 않는다. 결과는 탐색적으로 보고하고 순수 인과효과 판단은 보류한다.

이번 범위는 정책 근거·선정 규칙·명단·계획 반영이다. 매출 수집·패널·효과 추정은 후속 단계다. 원문 현황 XLSX와 정책 HWPX·PDF는 실제 취득했지만 매출 원자료를 열람하거나 분석하지 않았다. 원문·가공 데이터·개인 메모는 Git 제외 대상이다.

## 오늘 작업과 남은 PR (2026-10-20)

오늘 비교군 20개 고정, 공개 정책 원문 근거 보강, 점포별 예외 확인의 한계와 제외·보류 사유를 계획에 반영하고 [PR #29](https://github.com/CausalInferenceLab/policy-effect-analytics-agent/pull/29)를 제출했다. 기존 20개 후보 전체를 편입한 것이며 최초 5개 구는 우선 조사 대상이었다. 인구 유사도나 매출 결과로 일부 구를 선별하지 않았다.

#29는 최신 main에서 #22의 수집 코드와 분리해 제출했다. 2026-10-20 확인 기준 두 PR 모두 열려 있으며 #29 최초 제출 커밋(`4cd1449`)의 로컬 검사와 원격 CI는 통과했다. 후속 커밋의 CI 상태는 PR에서 확인한다. 리뷰·병합은 남아 있고, 같은 문서를 수정하므로 병합 순서에 따라 충돌 정리가 필요할 수 있다.

| 남은 PR | 작업 범위 | 완료 기준 |
|---|---|---|
| 수집·분석 PR | 매출·공간 버전 확인, 실제 다운로드, 동대문+비교군 20개 패널 구성, 품질 검사, 계획된 추정·반증 검사 | 수집부터 분석까지 재현 가능하며 결과 또는 중단 사유가 기록됨 |
| 리포트 PR | 결과·그림, discussion.md의 해석·한계, 보고서 생성과 재현 안내 | 보고서와 산출물이 일치하고 다른 참여자가 재현 가능 |

수집·품질 검사·추정은 하나의 수집·분석 PR 안에서 순차 진행한다. 매출 원자료 열람·패널 생성·효과 추정은 아직 하지 않았다. 점포 예외 전수 확인은 선행 조건에서 제외하되 입력 품질 기준과 탐색적 해석 원칙은 유지한다. 상세 작업과 공식 목표일은 [계획](plan.md#8-제출-순서와-남은-일)에 기록한다.
