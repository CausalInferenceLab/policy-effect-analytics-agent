# 정책 이력과 비교 후보 확인표

근거 확인 기준일: 2026-10-05. 문서 정리일: 2026-10-11.

10월 5일까지 찾아본 자료를 정리한 표다. 이번에 새로 조사한 내용은 없다. 변경 고시를 찾지 못했다고 해서 일요일 휴업을 유지했다고 볼 수는 없다. 아직 비교 후보 중 분석 기간 전체의 휴업일을 확인한 구는 없다.

현재 [plan.yaml](plan.yaml)에서는 동대문구를 처치 지역으로 정했다. 서초·중구·관악은 제외하고 성동은 추가 확인 전까지 넣지 않는다. 나머지 20개 구는 비교 후보로 두었다. 표의 역할은 이 계획에 따른 구분이다.

## 언제·누가·무엇을 확인했나

- 언제: 동대문구 고시 2024-16호의 효력일은 2024-01-29, 일부 점포는 2024-02-26이다. 분석 시작은 전환을 마친 뒤 첫 온전한 분기인 2024Q2로 잡았다.
- 누가: 동대문구를 처치 지역으로 사용한다. 비교 후보는 분석 기간 동안 어떤 점포에 어떤 휴업 기준이 적용됐는지, 일시적인 예외가 있었는지 더 확인해야 한다.
- 무엇: 골목상권의 육류·수산물·청과·반찬 판매 추정매출 합계의 자연로그를 사용한다. 매출 제공 설명과 API 명세는 확인했지만 원자료는 아직 열어보지 않았다. 영역 공간 ZIP은 다운로드해 코드·연결 구조를 확인했으며, 최신 매출 자료와 상권 경계·코드가 맞는지는 아직 확인하지 못했다.

## 함께 확인할 내용

동대문구 연계 지원사업은 [서울시의회 결산 기록](https://mas.smc.seoul.kr/record/recordView.do?key=8eee9ad6c34937762f150a6f45cd72764c6ae28cc71e710e19b7efc806f5ebd847d57163f338eb45)에서 확인했으나 구별로 실제 사업을 시작한 날과 대상지는 아직 확인하지 못했다. 예산이 교부된 날부터 매출에 영향을 주었다고 가정하지 않으며, 매출 변화를 휴업 요일 변경만의 효과로 해석하지 않는다.

매출과 영역 자료의 출처·이용 조건·확인 범위는 [plan.md의 자료원과 수집 설계](plan.md#4-자료원과-수집-설계)에 정리했다. 코드가 연결되더라도 해마다 같은 상권 범위와 기준으로 매출을 집계했는지 따로 확인해야 한다.

실제로 비교할 지역과 어디까지 확인했는지는 매출 결과를 보기 전에 정한다. 정책 이력, 함께 시행된 지원사업, 상권 자료의 기준이 불분명하면 정책 효과에 대한 판단은 보류한다. 확인이 덜 된 후보를 넣어 계산한 결과는 탐색적으로만 제시한다. 입력 오류나 매출 누락이 해결되지 않으면 실제 자료 분석을 멈춘다.
