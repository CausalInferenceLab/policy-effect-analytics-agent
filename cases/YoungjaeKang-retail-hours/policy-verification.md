# 정책 이력과 비교 후보 확인표

최초 근거 확인: 2026-10-05. 최근 조사: 2026-10-13(동대문 2024-121호 첨부 대상 목록 확인, 점포 예외의 공백 구체화).

기존 강북구 점포별 처분·서울시 2023년 한시 변경 조사에 동대문구 2024년 추석 고시의 첨부 확인 결과를 추가했다. 서울 25개 구를 대상으로 공개 검색과 저장소 조례 목록을 점검했지만, 구보·고시 전체를 전수 열람한 것은 아니다. 나머지 구는 기존 확인 수준을 유지한다. 변경 고시를 찾지 못했다고 해서 일요일 휴업을 유지했다고 볼 수는 없다. 아직 비교 후보 중 분석 기간 전체의 휴업일을 확인한 구는 없다.

현재 [plan.yaml](plan.yaml)에서는 동대문구를 처치 지역으로 정했다. 서초·중구·관악은 제외하고 성동은 추가 확인 전까지 넣지 않는다. 나머지 20개 구는 비교 후보로 두었다. 표의 역할은 이 계획에 따른 구분이다.

## 언제·누가·무엇을 확인했나

- 언제: 동대문구 고시 2024-16호의 효력일은 2024-01-29, 일부 점포는 2024-02-26이다. 분석 시작은 전환을 마친 뒤 첫 온전한 분기인 2024Q2로 잡았다.
- 누가: 동대문구를 처치 지역으로 사용한다. 비교 후보는 분석 기간 동안 어떤 점포에 어떤 휴업 기준이 적용됐는지, 일시적인 예외가 있었는지 더 확인해야 한다.
- 무엇: 골목상권의 육류·수산물·청과·반찬 판매 추정매출 합계의 자연로그를 사용한다. 매출 제공 설명과 API 명세는 확인했지만 원자료는 아직 열어보지 않았다. 영역 공간 ZIP은 다운로드해 코드·연결 구조를 확인했으며, 최신 매출 자료와 상권 경계·코드가 맞는지는 아직 확인하지 못했다.

## 함께 확인할 내용

동대문구 연계 지원사업은 [서울시의회 결산 기록](https://mas.smc.seoul.kr/record/recordView.do?key=8eee9ad6c34937762f150a6f45cd72764c6ae28cc71e710e19b7efc806f5ebd847d57163f338eb45)에서 확인했으나 구별로 실제 사업을 시작한 날과 대상지는 아직 확인하지 못했다. 예산이 교부된 날부터 매출에 영향을 주었다고 가정하지 않으며, 매출 변화를 휴업 요일 변경만의 효과로 해석하지 않는다.

매출과 영역 자료의 출처·이용 조건·확인 범위는 [plan.md의 자료원과 수집 설계](plan.md#4-자료원과-수집-설계)에 정리했다. 코드가 연결되더라도 해마다 같은 상권 범위와 기준으로 매출을 집계했는지 따로 확인해야 한다.

실제로 비교할 지역과 어디까지 확인했는지는 매출 결과를 보기 전에 정한다. 정책 이력, 함께 시행된 지원사업, 상권 자료의 기준이 불분명하면 정책 효과에 대한 판단은 보류한다. 확인이 덜 된 후보를 넣어 계산한 결과는 탐색적으로만 제시한다. 입력 오류나 매출 누락이 해결되지 않으면 실제 자료 분석을 멈춘다.

## 비교 후보 조사 기준과 기록 형식

전수 조사 범위는 서울 25개 구이며 선정 기준은 [plan.md](plan.md#비교군-선정-기준--전수-조사-전에-정할-사항)에 따른다. 종로·용산·광진·중랑·성북은 기록 형식을 점검한 첫 작업 묶음으로, 인접성·인구·상권 유사성에 따라 선정한 비교군이 아니다. 이번에는 공개 웹 검색, 의회 기록, 국가법령정보센터 연혁 화면, 공공데이터 제공 설명을 확인했다. 구청 고시·공고 전체와 첨부파일을 전수 열람한 조사는 아니다.

기록은 다음 항목으로 통일한다. 문서 한 건의 날짜를 구 전체의 정책 시행일로 사용하지 않는다.

| 항목 | 기록 방법 |
|---|---|
| 문서·출처 | 제목, 발행기관, URL, 확인일, 본문 또는 검색 요약 확인 여부 |
| 날짜 | 게시·발표일, 의결일, 효력일, 첫 적용 휴업일, 종료일을 구분. 확인하지 못한 값은 미확인 |
| 적용 대상 | 대형마트·SSM·개별 점포명, 적용 제외 점포와 근거 |
| 휴업 규칙 | 변경 전후 요일, 영구 전환·한시 대체·규제 제외를 구분 |
| 기간 범위 | 해당 문서가 직접 뒷받침하는 시점. 2021~2024 이전·이후 자료는 당시 이력의 단서로만 사용 |
| 비교군 판단 | 포함 가능·제외·미확인과 이유. 검색에서 변경 고시가 안 나왔다는 사실은 유지 근거가 아님 |
| 공간 파급 | 동대문 인접 여부와 다른 구의 전환 점포 이용 가능성. 경계 자료·점포 위치 확인 전에는 미확인 |
| 다음 확인 | 부족한 기간·점포·고시를 구체적으로 기록 |

‘포함 가능’은 적용 대상과 기간 내 변경·예외를 검토해 비교군으로 쓸 근거가 확보된 경우의 검토 의견이다. 정기 평일 전환, 명절의 일회성 휴업일 대체, 농수산물 매출 비중에 따른 적용 제외는 서로 다르다. 예외를 발견했다는 이유만으로 구 전체를 즉시 제외하지 않고 기간·대상·분기 노출을 검토한 뒤 계획에 반영한다.

첫 5개 구의 현재 판단은 모두 **미확인**이다. 기존 비교 후보 지위는 유지하며 실행 목록을 확정하지 않았다. 동대문 인접 여부의 공식 경계 대조와 구별 소비 이동 근거 정리도 남아 있다.

서울 25개 구의 [공통 조사표](comparison-survey.md)와 [자료원·지표 정의](data-notes.md)를 마련했다. 특성 값과 최종 비교군은 아직 확정하지 않았다.

- 대형마트 2곳: 홈플러스 동대문점, 롯데마트 청량리점.
- 준대규모점포 10곳: 이마트에브리데이 이문점·답십리점, 롯데슈퍼 장안점·전농점·마켓999이문점, 노브랜드 경동시장점·동대문장안점, 홈플러스 익스프레스 서울회기점, GS THE FRESH 동대문장안점·장안한내점.

이 고시는 **2024-08-21 시행**이며 9월 둘째 휴업일을 11일에서 17일로 옮기고, 넷째 수요일인 25일은 유지한다. 시행일과 실제 휴업일을 구분한다. 경동시장점은 이 시점의 대상 목록에 명시돼 있으나 2023년 안내의 적용 제외 사유·기간까지 확인된 것은 아니다. 두 문서 사이에 점포 규칙이 어떻게 이어졌는지 별도 처분으로 확인해야 한다. 2024년 목록을 2022년 영업 점포 수로 사용하지 않는다.

## 서울시 7개 구 한시 변경 안내

[서울시 안내](https://news.seoul.go.kr/economy/archives/548590)(수정일 2023-11-02)는 코리아세일페스타에 맞춰 **종로·동대문·중랑·마포·강서·영등포·서초**의 휴업일을 2023-11-12에서 11-05로 옮기는 일정과 대상 점포를 제공한다. 두 날짜 모두 일요일이며 정기 평일 전환으로 분류하지 않는다. 목록에 없는 구의 미변경이나 대상 외 점포의 규칙을 역으로 추정하지 않는다.

종로의 SSM 존재와 마포·강서·영등포의 기간 내 대상 목록을 확인하는 근거로 추가했다. 동대문 **노브랜드 경동시장점은 ‘적용 제외’로 표시**돼 있다. 이 문구만으로 규제 자체가 면제됐다고 해석하지 않는다. 한시 변경 제외인지, 별도 휴업 규칙 때문인지 구 처분 원문 확인이 필요하다. 2024-121호 첨부에는 같은 점포가 대상에 포함되므로 기간을 특정하지 않은 상시 면제로 기록하지 않는다. 목록의 점포명은 당시 안내 표기이며 2022년 영업 점포 수로 소급하지 않는다.

이 사건은 처치구와 일부 비교 후보가 함께 겪은 변화다. 동대문만의 사건으로 설명하거나 모든 구가 같은 영향을 받았다고 가정하지 않는다. 2023Q4 사전 계수 해석에 해당 구들과 남은 구들의 차이를 함께 기록한다.

## 이번 게시판 검색의 범위와 한계

- 마포·도봉·양천 공식 고시 게시판에서 `의무휴업`, `대규모`를 각각 검색했으나 해당 응답에 일치 자료가 없었다. 이는 검색 결과이며, 휴업 지정이나 변경이 없었다는 증거가 아니다. 띄어쓰기·다른 제목·구보 및 과거 게시판 보존 범위 확인이 남는다.
- 강북 대표 도메인의 목록 응답은 본문이 비어 있어 검색 성공으로 기록하지 않았다. 동일 구청의 `child.gangbuk.go.kr/portal/` 게시판에서 관련 문서를 확보했다.
- 공식 안내의 대상 목록, 개별 처분, 전체 기간 확인을 구분한다. 이번 보강 후에도 최종 기본 비교군은 확정하지 않았다.
