# 정책 전 특성자료 수집·검사 계획

작성일: 2026-10-13. 서울 25개 자치구의 정책 전 특성을 같은 기준으로 설명하기 위한 사전 계획이다. 출처와 확인 이력은 [자료 노트](data-notes.md), 비교군 선정 원칙은 [분석 계획](plan.md)을 따른다. 이 사전 계획 작성 시점에는 특성 수치와 매출 원자료를 수집하지 않았다. 이후 가구·면적의 첫 로컬 실행 상태는 [자료 노트](data-notes.md#첫-로컬-실행-결과)에 별도 기록한다.

## 범위와 시작 조건

공개 자료로 재현할 수 있는 수집·검사를 작업 범위로 삼는다. 기관 직접 문의·정보공개청구·회신 대기는 포함하지 않는다. 공개 자료에서 해결되지 않는 정책·자료 공백은 미확인으로 기록하고 해당 판단·산출을 보류하되, 독립적인 코드 구현과 자료 검사는 진행한다.

처치·비교 후보·제외·보류 여부와 관계없이 서울 25개 구 모두를 수집 대상으로 둔다. 2022년을 목표 연도로 고정하되 아래 항목별 기준시점은 그대로 보존한다. 특성값은 비교 가능성을 설명하는 용도이며 회귀 통제변수, 유사도 점수 또는 자동 편입·탈락 기준으로 사용하지 않는다.

이번 계획을 커밋·PR한 뒤 후속 PR에서 특성자료 수집·검사 코드를 구현한다. 수집 전에 자료별 이용 조건을 확인하고, 내려받은 파일의 시점·정의·공간 버전 검사를 통과한 항목만 특성표의 검증된 값으로 사용한다. 원자료를 열어야 확인할 수 있는 항목은 아래의 조건부 절차에 따라 처리한다. 다른 연도·정의로 바꿔야 한다면 대체 자료를 수집하기 전에 계획 변경과 이유를 커밋·PR한다.

가구·면적은 연결 통계표에서 2022년을 지정한 내보내기를 우선 사용하고, 점포·시장은 위의 과거 파일을 우선 사용한다. 공개 다운로드가 수동으로만 가능하면 조회 조건과 공식 취득 절차를 README에 남기고, 후속 코드는 로컬 원본에서 정제·검사를 재현하도록 한다. 파일 취득까지 자동화됐다고 설명하지 않는다. API로 전환할 때는 같은 시점·정의·버전인지 먼저 대조하고 필요한 키 설정을 별도로 안내한다.

대형마트·SSM의 2022년 말 영업 수, 규제 제외 점포 수, 공식 경계 기반 인접성은 아직 자료 확보 경로가 충분하지 않다. [정책 확인 공백](verification-gaps.md)과 함께 계속 조사하되 이번 수집의 완료 항목으로 계산하지 않는다. 최신 인허가 파일의 현재 영업 상태나 등록일만으로 과거 영업·휴업 규칙을 복원하지 않는다. OA-23058의 현재 전통시장 API도 2022년 파일의 대체 자료로 사용하지 않는다.

## 정제·파생 지표

원본 지역 코드와 코드 체계를 보존하고, 공식 자료의 구명·코드 대응을 확인해 `gu_code`로 연결한다. 서울 합계·동 단위 행은 자치구 행에 더하지 않는다. 출처별 대응표는 25개 구 각각에 유일한 연결이 있어야 하며, 불명확한 이름이나 코드를 추측해서 채우지 않는다.

- 고령인구 비율: 같은 시점의 65세 이상 인구 / 전체 주민등록인구 × 100.
- 인구밀도: 2022년 12월 말 주민등록인구 / 기준일을 확인한 2022년 행정면적(km²). 두 자료의 실제 기준일을 함께 표시한다.
- 1인 가구 비율: 2022년 1인 일반가구 / 전체 일반가구 × 100.
- 식품판매 점포 수: 골목상권의 전체 점포 수를 구×업종별 합산. 네 업종 합계와 각 업종 / 네 업종 합계 × 100을 함께 기록한다.
- 시장 수·존재 여부: 자료의 공식 식별자가 있으면 이를 사용한다. 없으면 구·시장명·주소로 중복 후보를 찾되, 서로 다른 시장인지 원문으로 해결하기 전에는 자동 병합하지 않는다. 포함할 시장 유형을 구별로 달리 적용하지 않는다.

점포 수는 4개 분기를 합산하지 않는다. 후속 공식 설명 확인에서 분기 중 폐업 점포도 포함하는 정의가 발견돼, 한 시점의 영업 재고라는 초기 설명을 철회한다. 해당 정의의 2022년 파일 적용 여부까지 확인하기 전 집계를 보류한다. 네 업종 중 일부가 누락되면 부분합을 전체 합계로 표시하지 않는다. 분모가 0이거나 결측이면 비율은 정의 불가로 남긴다. 공간 연결이 불명확한 상권은 임의 배분하지 않는다.

## 누락·오류 처리와 완료 기준

| 검사 | 처리 |
|---|---|
| 구 범위 | 출력에는 25개 구를 모두 유지하고 구×지표×기준시점은 유일해야 함. 자료가 없는 구도 상태와 사유를 가진 행으로 보존 |
| 응답·파일 | HTML 오류·로그인 응답을 CSV/XLSX/ZIP 취득 성공으로 기록하지 않음. 빈 파일, 필요한 시트·열·분기 부재는 실패 기록 |
| 시점·정의 | 목표 연도·분기, 가구 모집단, 시장 유형, 공간 버전을 대조. 기준이 다르면 해당 지표의 산출 중단 |
| 수치 | 인구·가구·점포·시장 수는 비음수 정수, 면적은 양수. 비율 0~100, 분자≤분모, 전체와 부분 합계 확인. 반올림된 값은 출처의 표시 정밀도로 허용 오차를 정하고 기록 |
| 비공개·결측 | 빈칸·`x`·기타 기호의 원문과 정의를 보존. 미수집·비공개·연결 실패를 0으로 채우지 않음. 보간·인접 연도 대체 없음 |
| 중복·연결 | 원본 키 중복과 상권→구 복수 연결을 보고하고 집계 중단. 원인 확인 없이 첫 행 선택·중복 제거 금지 |
| 0의 인정 | 공식 자료의 명시적인 0 또는 완전한 대상 목록과 부재 근거를 확인한 경우만 허용. 목록에 행이 없다는 이유만으로 0을 생성하지 않음 |

항목의 오류는 그 항목과 이를 사용하는 파생 지표를 보류하며, 독립적인 다른 자료의 검사까지 막지는 않는다. 특성자료가 부족하다는 이유만으로 비교 후보를 자동 탈락시키지 않는다. 최종 비교군은 별도 PR에서 정책 이력·확인 수준과 함께 판단한다.

수집·검사 PR의 완료 기준은 **실제 취득 가능한 항목을 재현하고, 25개 구의 모든 계획 지표에 값 또는 보류 사유가 남으며, 해결되지 않은 오류가 성공으로 표시되지 않는 것**이다. 일부 값이 보류되면 전체 특성표를 완성했다고 보고하지 않는다. 정책 이력 전체 확인과 효과 추정 완료는 별개다.

## 저장·실행 계약

후속 코드의 산출 위치는 사례 폴더 아래 `data/characteristics/`로 정한다. 원본은 `data/raw/characteristics/<수집시각-고유번호>/<자료원>/`에 보관하며 기존 파일을 조용히 덮어쓰지 않는다. 원본·가공 값·검사 기록은 Git에서 제외한다. 첫 로컬 구현에서는 두 자료를 같은 실행 단위로 재검사하도록 당초 자료원/수집일 경로의 순서를 조정했다.

| 산출물 | 내용 |
|---|---|
| `data/characteristics/values.csv` | 구×지표×기준시점별 값·단위·분자·분모, `status`, `reason`, `source_id`. 값이 보류되면 숫자 칸은 비움 |
| `data/characteristics/sources.json` | `source_id`, 공식 URL, 조회 조건, 원파일명·로컬 경로·SHA-256, 취득 시각, 이용 조건, 시점·공간·업종 정의, 변환 코드의 커밋 |
| `data/characteristics/quality.json` | 검사명·자료원·대상 구·통과/보류/실패·사유·문제 건수. 취득 오류도 기록 |

값의 `status`는 `verified`(정의·품질 확인), `not_collected`(미수집), `suppressed`(비공개), `unresolved`(정의·연결 등 미해결), `undefined`(분모 0 등)로 구분한다. 이 상태값과 정책 적격성은 서로 다른 항목이다.

이 단계는 매출 패널 `data/panel.csv`를 만들지 않으며 `make flow`로 실행하지 않는다. 공통 `collect`는 첫 번째 `data_sources`의 패널을 사용하고, 공통 `quality_checks`는 추정 패널의 열·시간·집단·중복 등을 검사한다. 여러 특성자료를 자동 수집하거나 위의 특성 검사를 대신하지 않는다. 후속 PR에서 별도 진입점과 사례별 검사를 구현한다. `plan.yaml`에는 실제 스키마의 `data_sources`·`notes`로 이 계획을 연결하고, 미구현 어댑터 이름이나 자동 검사 필드를 만들어 넣지 않는다.

## 후속 확인에 따른 우선순위

2026-10-13 사용자 합의: 공개 설명과 원자료를 확인해도 점포 자료의 집계 근거가 부족하면 보류하고 다음 자료로 넘어간다. 다른 특성으로 비교가 어려우면 인구수 중심의 비교 설명도 검토한다. 인구만으로 자동 매칭하거나 비교군을 확정한다는 결정은 아니다.

점포는 누락 행의 의미·공간 버전·분기 중 폐업 포함 정의의 적용 문제가 남아 구별 합계·구성비와 상권 수를 보류한다. 다음 우선순위는 기존 계획의 2022-12 주민등록인구와 연령 구성이다. [동일 인구 통계의 공식 제공목록](https://www.data.go.kr/data/3033304/fileData.do)에서 `ageStatMonth.do` 연결과 이용허락범위 제한 없음을 확인해 이용 조건 확인 단계는 통과했다. 당시에는 실제 2022년 CSV 취득·검사가 남아 있었으며, 후속 실행에서 완료했다. 최신 결과는 자료 노트의 인구 실제 다운로드 기록을 참조한다. 자료원·목표 시점·분석 결과변수는 변경하지 않았다.
