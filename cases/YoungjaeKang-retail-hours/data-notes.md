최근 확인일: 2026-10-13. [선정 기준](plan.md#비교군-선정-기준--전수-조사-전에-정할-사항)에 따라 서울 25개 구를 같은 정의로 조사하기 위한 자료원 점검이다. 제공 설명·API 명세·통계표의 연도 선택 항목을 확인했으며, 아래 특성 파일을 내려받거나 지역별 값을 산출하지 않았다. 매출 원자료도 열지 않았다.

## 추가 확인 — 2026-10-12

- **가구·면적:** 열린데이터광장의 Sheet가 연결하는 서울 통계 조회 화면을 직접 열어 두 표 모두 `2022` 연도 선택 항목을 확인했다. 가구 표의 수록기간 표시는 2000~2025년, 면적 표는 1960~2025년이다. 이는 조회 선택지 확인이며, 25개 구의 값이나 파일 수집 완료가 아니다. 가구 제공 페이지의 요약 갱신주기는 여전히 ‘5년’이나 상세 설명은 2016년 이후 연간으로 명시하므로 상세 설명과 실제 연도 선택 항목을 함께 기록한다.
- **전통시장:** [API 명세](https://data.seoul.go.kr/dataList/openApiView.do?infId=OA-23058&srvType=A&serviceKind=1)의 서비스는 `aiListTraditionalMarket`이고 선택 조건은 자치구 `CGG`다. 출력 12개 항목에도 연도·기준일이 없다. 제공 페이지의 시간범위만으로 연도별 패널로 해석하지 않는다. 현 API의 시장 수를 2022년 값으로 쓰는 경로는 보류한다. 대체 경로 OA-1176에서 **2022년 상반기 기준 XLSX** 목록을 찾았다. 파일 내부의 정확한 기준일을 확인한 뒤 모든 구에 동일하게 적용하고, 연말 인구·4분기 점포 수와 시점 차이를 표시한다.
- **점포:** [API 명세](https://data.seoul.go.kr/dataList/openApiView.do?infId=OA-15577&srvType=A&serviceKind=1)에서 `STDR_YYQU_CD`, `TRDAR_CD`, `TRDAR_SE_CD`, `SVC_INDUTY_CD`와 점포 수 필드를 확인했다. 전체 점포 수는 **`SIMILR_INDUTY_STOR_CO`**, 일반 점포 수는 `STOR_CO`, 프랜차이즈는 `FRC_STOR_CO`다. `STOR_CO`만 집계하면 계획의 전체 점포 수와 달라진다. 명세에는 자치구 코드 출력이 없어 영역 자료와 연결해야 한다.
- **공간 기준:** [서비스 소개](https://golmok.seoul.go.kr/introduce.do)는 발달상권·전통시장 영역 구축에 2022년 표준단위구역을 사용한다고 설명한다. 반면 OA-15560에서 확인되는 ZIP 수정일은 2023-10-23이다. 이 두 사실만으로 골목상권 경계나 과거 점포·매출의 공간 기준이 같다고 입증되지 않는다. 현재 제공하는 영역과 ZIP의 버전 대조가 남는다.

## 값과 근거의 보관 규칙

각 값은 `자치구명 / 지표 / 값 / 단위 / 기준시점 / 분자·분모 / 출처 URL / 원파일명·해시 / 조회 조건 / 공간·업종 버전 / 확인일 / 상태 / 미확인 사유`와 함께 기록한다. 구 코드는 출처별 코드 체계를 확인한 후 연결하며 이름만 보고 임의 코드를 입력하지 않는다.

상태는 ‘자료원 후보 → 제공 설명 확인 → 해당 연도 목록 확인 → 다운로드 확인 → 정의·품질 확인’으로 구분한다. 미수집·미확인·정의 불가를 숫자 0으로 저장하지 않는다. 0은 해당 시점에 없음을 공식 자료로 확인했을 때만 사용한다. 원자료·산출물 저장 위치와 취득 절차는 [수집 계획](collection-plan.md#저장실행-계약)을 따른다.

지역별 진행 상황은 [공통 조사표](comparison-survey.md)에 기록한다. 이 특성들은 선정 근거를 설명하기 위한 것이며, 자동으로 회귀 공변량·매칭 점수에 추가하지 않는다.


## API 키 필요 여부

현재 정책 고시·공개 통계 화면·파일 목록 확인에는 키를 사용하지 않았다. 공개 파일로 같은 기준의 자료를 확보할 수 있는지 먼저 확인하며, API 호출이 필요한 경우에만 설정을 요청한다. 아직 인증된 API 호출 성공이나 과거 자료 복원을 확인한 것은 아니다.

- **서울 열린데이터광장:** [공식 이용안내](https://data.seoul.go.kr/together/guide/useGuide.do)의 일반 인증키를 발급받는 방식이다. 공공데이터포털 키와 별개다. 점포 ZIP 등 공개 파일 경로도 확인돼 현재 발급을 필수로 요청하지 않는다. 사례 수집 코드에서 사용할 환경변수명과 호출 경로는 구현 시 확정한다.
- **공공데이터포털:** [대규모점포 API](https://www.data.go.kr/data/15154948/openapi.do)를 사용할 때는 해당 서비스 활용신청·승인과 인증키가 필요하다. 저장소의 기존 설정명은 `DATA_GO_KR_API_KEY`다. 키가 있어도 2022년 영업·규제 이력을 복원할 수 있는지는 별도 검증한다.
- **KOSIS:** 저장소의 기존 설정명은 `KOSIS_API_KEY`다. 현재 서울 통계표·공개 파일 대체 경로를 조사하고 있어 발급 필요 여부는 미정이다.

설정이 필요해지면 사용할 서비스와 로컬 설정 위치를 안내한다. 키는 채팅·문서·커밋에 넣지 않고 로컬 환경변수 또는 Git 제외된 `.env`에 보관한다.
