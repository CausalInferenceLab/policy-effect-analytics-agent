# 서울 기후동행카드 도시 비교 케이스

서울 기후동행카드 시범사업 전후의 지하철 승차 흐름을 서울과 부산·대구·광주·대전으로 비교합니다.

## 한 줄 요약

개인 저장소의 기존 자체 분석에서 서울의 평일 승차는 시범사업 뒤 3개월 동안 비교 도시 평균보다 약 3% 더 늘었지만, 다른 도시를 가짜 정책 도시로 바꿔도 비슷하거나 더 큰 변화가 나왔습니다. 따라서 **정책 효과가 입증됐다고 말하지 않고 ‘조건부’로 판단**했습니다.

## 중요한 정직한 기록

- 최초 서울·부산 분석의 계획은 결과를 보기 전에 작성했습니다.
- 계획 2는 서울·부산 결과를 본 뒤 만들었지만, 대구·광주·대전 자료를 열기 전에 개인 저장소 commit `87f5222`로 기록했습니다.
- 이 폴더의 `plan.yaml`은 기존 계획을 멘토 스키마에 맞춘 것이며, 새로운 사전등록이라고 주장하지 않습니다.
- 기존 +3.0% 결과는 개인 저장소의 자체 코드가 만든 결과입니다. 멘토 엔진 결과와 같다고 미리 단정하지 않습니다.

## 실행

```bash
pip install -e ".[dev]"
python cases/jm-git-163-climate-card/fetch.py
make flow CASE=cases/jm-git-163-climate-card
```

`fetch.py`는 개인 저장소의 고정 커밋에 있는 도시×월 스냅샷을 내려받아 `data/panel.csv`를 만듭니다. 원자료 정리 과정은 개인 저장소의 `src/prepare.py`, `src/prepare_cities.py`에 공개되어 있습니다.

`make flow`는 계획 파일의 git 커밋을 확인합니다. 이 사례는 기존 결과를 본 뒤 옮긴 회고적 재현 케이스이므로, 커밋 여부와 무관하게 새로운 사전등록으로 해석하지 않습니다.

## 데이터와 분석 단위

- 기간: 2022-07~2024-04, 2024-01 전환 월 제외
- 단위: 도시 5곳 × 월 21개 = 105행
- 처치 도시: 서울
- 비교 도시: 부산·대구·광주·대전
- 결과 지표: 도시별 평일 하루 평균 승차 합계의 로그

## 기존 자체 분석 결과

- 서울과 비교 도시 평균의 변화 차이: 약 **+3.0%**
- 서울의 가짜 지역 순위: 5곳 중 **3번째**
- 대구·대전 제외 시: 약 **+1.4%**
- 판정: **조건부**

도시가 5곳뿐이면 가짜 지역 순위의 가장 작은 가능한 값도 1/5=0.2입니다. 일반적인 5% 기준을 만족할 수 없으므로 강한 인과 결론을 내릴 수 없습니다.
