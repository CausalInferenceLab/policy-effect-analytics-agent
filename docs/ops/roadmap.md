# 점검과 다음 계획 (2026-10-25 기준)

이 프로젝트의 목표는 세 가지입니다.

1. 공공·사회 문제를 데이터로 정의하고, 정책이 실제로 어떤 효과를 냈는지 추정한다.
2. 수집 → 지표 → 추정 → 리포트를 LLM 에이전트로 자동화한다.
3. 같은 문제를 다루는 누구나 바로 쓸 수 있도록 레포와 분석 사이트를 공개한다.

7주 동안 만든 것과 드러난 문제를 숫자로 점검하고, 계획을 다시 세웠습니다. 계획은 **관문**(다음 단계로 넘어가기 전에 확인할 것) 기준으로 움직입니다.

## 지금까지 만든 것

- 사이트: 분석 결과(답 페이지), 주제 9개, 지금 이슈 7개, 데이터 지도(48개), 데이터 계보, 참여자 프로젝트, 공개 API
- 참여자 결과 4개(대형마트 영업시간, 창원 통합 2개, 서울 출산지원) + 멘토 예시 2개(기후동행카드 성남 편입, 토지거래허가구역)

| 문제 | 근거 | 왜 문제인가 |
|---|---|---|
| 쓰임새를 가정만 했다 | 사이트 대화에서 올라온 질문 0건, 외부 사용자 테스트 0회 | 목표 3("누구나 바로 쓸 수 있게")을 확인한 적이 없다 |
| 리뷰가 없다 | 멘티 PR 18건 중 리뷰 0건 | 계획·해석의 오류를 아무도 보지 않은 채 합쳐졌다 |
| 사전 등록이 형식뿐이다 | 게이트는 `plan.yaml`이 커밋됐는지만 본다. 결과 6개 중 5개는 계획과 결과가 같은 날 커밋, 1개는 결과와 함께 계획 수정 (멘토 예시 포함) | 결과를 보고 계획을 맞췄는지 기록으로 구분할 수 없다 |
| "판별 못함"만 나온다 | 참여자 결과 4개 모두 '크기를 판별하지 못함' 또는 '판단 불가' | 사용자가 가져갈 문장이 없다. "이 크기 이상은 아니었다"(배제 범위)는 말할 수 있는데 쓰지 않았다 |
| 필요한 추정 도구를 미뤘다 | 4주차에 권장한 시차 도입·합성통제 모듈을 만들지 않고 사이트 기능에 시간을 썼다 | 실제 정책 대부분이 지역마다 시작일이 다르다 |
| '에이전틱' 목표와 거리 | 제품 안 분석 흐름은 규칙 기반. LLM 에이전트는 운영(PM) 쪽에만 쓰였다 | 목표 2가 사용자에게 보이지 않는다 |
| 재현·갱신이 멈췄다 | 독립 재현 0건. 법령 스냅샷이 9.27 이후 갱신 안 됨(법제처 인증값 미등록) | "재현 가능"과 "최신"이라는 약속을 지키지 못한다 |

## 다시 세운 계획

### 1단계 — 수료(11.1)까지: 믿을 수 있게, 쓸 수 있게

- [x] 답 페이지에 **이 결과를 얼마나 믿을 수 있나** 표시: 사전 등록 기록(git 시각 비교), 교차 재현, 한 문장 해석, 실행 상태
- [x] '크기를 판별하지 못함' 결과에 **배제 범위** 문장 자동 추가
- [x] 참여자 카드에 **다음 할 일** 자동 표시 (한 문장 해석, 교차 재현 요청, 계획 PR 먼저 등)
- [x] 법령 목록이 14일 넘게 갱신되지 않으면 주제 페이지에 경고
- [x] 첫 화면을 사용자 과업 4개(결과 찾기 · 질문 · 우리 지역 적용 · 참여)로 시작
- [ ] **외부인 5명 과업 테스트** — [user-test.md](user-test.md) 순서대로, 결과는 `사용자 과업 테스트 기록` 이슈로
- [ ] **짝 리뷰 · 교차 재현** — 결과가 나온 케이스마다 다른 참여자 1명이 `교차 재현 기록` 이슈를 남기고, 확인되면 `catalog/projects.yaml`의 `reproduced_by`에 추가
- [ ] 모든 결과의 `discussion.md`에 '결과를 한 문장으로' 채우기
- [ ] 법제처 인증값(Actions 시크릿) 등록, Draft PR 정리

**관문**: 외부인 5명 중 4명 이상이 결과를 혼자 찾고, 판정을 넘지 않는 문장으로 인용한다.

- [x] 배제 범위를 리포트(`report.md`)·API(`results.json`·`results.csv`)에도 넣기 — `core/report/interpret.py`
