# 점검과 다음 계획

이 프로젝트의 목표는 세 가지입니다.

1. 공공·사회 문제를 데이터로 정의하고, 정책이 실제로 어떤 효과를 냈는지 추정한다.

### 새로 드러난 문제

1. **무작위화 추론 p값이 실제보다 작게 나왔다(코어 버그).** 처치 1곳·대조 5곳처럼 가짜 배정이 5가지뿐인데 999번 중복 추첨해 p가 0.001까지 내려갔다. 정확한 최솟값은 1/6이다. 서울 출산지원(p 0.001 → 최소 0.25)과 대구 대형마트(사전추세 p 0.001 → 검정 불가)가 영향을 받는다. 이 문제를 처음 짚은 것은 리뷰가 아니라 참여자(@jgkim1008)의 discussion.md였다 — 리뷰가 있었다면 더 일찍 잡았을 것이다. 수정: #60.
2. **머지가 리뷰 없이 이뤄진다.** 이번 정리에서도 자동 머지가 "리뷰 없는 머지"로 막혔다. 리뷰 0건은 운영 습관이 아니라 규칙의 부재다.
3. **사이트가 '흐름'을 보여 주지 못했다.** 이슈·데이터·계보·분석이 각각 다른 화면에 흩어져 있어, 한 이슈가 어디까지 왔는지 한눈에 볼 수 없었다. → 이번 개편에서 이슈 보드로 묶음.
4. **대시보드의 구간 표시는 참고용이다.** 처치 단위가 적은 케이스의 시점별 세로선은 군집-강건 표준오차라 실제 불확실성보다 좁다. 그림에 그렇게 적었지만, 그림이 숫자보다 더 강하게 읽힌다는 점을 기억해야 한다.
5. **'에이전틱' 목표는 그대로 비어 있다.** 제품 안 분석 흐름은 여전히 규칙 기반이다. 3단계로 미룬 것을 숨기지 않는다.
