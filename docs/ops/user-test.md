# 사용자 과업 테스트 (외부인 5명)

사이트가 "누구나 바로 쓸 수 있는지"를 직접 확인합니다. 레포를 모르는 사람 5명에게 아래 과업을 맡기고, **도와주지 않고** 지켜봅니다.

## 누구에게

이 결과를 실제로 쓸 만한 사람: 지역 언론 기자, 지자체·공공기관 실무자, 정책·사회과학 대학원생, 시민단체 활동가, 데이터에 관심 있는 개발자. 같은 직군에서 2명 넘게 받지 않습니다.

## 진행 (한 사람 20분)

1. 사이트 첫 화면 주소만 줍니다: https://causalinferencelab.github.io/policy-effect-analytics-agent/
2. "생각나는 대로 소리 내어 말해 주세요"라고 부탁합니다.
3. 과업을 하나씩 읽어 줍니다. 3분 안에 못 하면 힌트 하나(어느 메뉴인지)를 주고 기록합니다.
4. 끝나면 [사용자 과업 테스트 기록](https://github.com/CausalInferenceLab/policy-effect-analytics-agent/issues/new?template=user-test.yml) 이슈를 씁니다. 이름·연락처는 적지 않습니다.

## 과업

| # | 과업 | 성공 기준 |
|---|---|---|
| 1 | "대형마트 의무휴업이 매출에 영향을 줬는지 이 사이트에 결과가 있나요?" | 답 페이지를 혼자 연다 |
| 2 | "그 결과를 기사나 보고서에 한 문장으로 쓴다면?" | 판정을 넘지 않는다 ('효과 없다'·'효과 있다'로 단정하지 않음) |
| 3 | "이 분석은 어떤 데이터를 썼고, 나도 받을 수 있나요?" | '쓴 공공데이터' 표와 받는 곳을 찾는다 |
| 4 | "요즘 궁금한 정책 하나를 물어보세요." | 대화창이 맞는 주제·데이터를 보여 준다 |
| 5 | "'판단 불가'는 무슨 뜻인가요?" | "효과가 없다"가 아니라 "이 자료·설계로는 판단할 수 없다"로 설명한다 |

## 판단

- **관문**: 5명 중 4명 이상이 과업 1·2를 힌트 없이 성공
- 가장 많이 머뭇거린 화면부터 고칩니다. 고친 뒤 다른 사람 2명에게 다시 확인합니다.
- 과업 2에서 단정이 나오면 답 페이지의 '이 결과를 쓰려면' 문구를 먼저 고칩니다.
